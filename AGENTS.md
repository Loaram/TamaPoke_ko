# Korean fork context

Read `HANDOFF.ko.md` and `README.ko.md` for the current project state before continuing work.

- This repository is Loaram's Korean edition of **DylanPDao/TamaPoke**. It covers National Dex 1–1025 across nine Pokédex regions. The 3.0.0 release has nine gym regions, including Sword/Shield Galar courses. See `docs/GYMS-GALAR-PALDEA.ko.md`. It is not the ShadowEnemyx Gen 3 fork.
- `HANDOVER.md` is an older upstream history, including another maintainer's board/save state. It is not evidence about the user's device.
- Korean UI uses `korean_text.h` and the generated font/name tables. Keep canonical IDs, saved nicknames, language indices, and radio record formats compatible.
- Version policy (user-defined): use plain `a.b.c`, without `ko.`. Increment `a` for new features or large changes (reset b/c to zero); increment `b` for feature corrections or balance patches (reset c to zero); increment `c` for text-only changes or small patches. Choose the highest applicable category automatically and explain the choice in release notes. Android/Wear versionCode must also increase monotonically, independently of this display version.
- See `docs/qa/3.0.0/README.md` for the current full-system release audit. Earlier build/emulator/web checks passed for 2.0.1, including Android save-apply shutdown and offline lifecycle regressions. Hardware, Android/Wear device-time and battery behavior, the 24-hour farewell boundary and Android-to-hardware LAN/Explore tests remain unverified until actual results are recorded. See the hardware test issue template and `docs/HARDWARE_TEST.ko.md`.
- For every numbered release, also build two private emulator variants: full normal Pokedex with `-dex` and full shiny Pokedex with `-shiny` (for example `2.0.0-dex` and `2.0.0-shiny`). Never publish or attach either executable to GitHub releases or Pages. Build them with `tools/build_emulator.py --full-dex` and `tools/build_emulator.py --full-shiny`; they use `tamapoke-dex.nvs` and `tamapoke-shiny.nvs` instead of the normal emulator save.
- Every numbered GitHub release must attach both public PDFs: the versioned play guide from `web/guides/TamaPoke-<version>-Play-Guide-KO.pdf` and the unchanged Watch4-9 installation guide from `docs/guides/TamaPoke-Galaxy-Watch4-9-Install-Guide-KO.pdf`, renamed `TamaPoke-<version>-Galaxy-Watch4-9-Install-Guide-KO.pdf`. Include both SHA-256 values in `SHA256SUMS.txt`. These are required public assets alongside the Android APK, Wear OS APK and ESP32 installer ZIP. Run `python tools/prepare_release_guides.py` when assembling every release.
- Use the commands and pinned board/library settings in `README.ko.md` and `HANDOFF.ko.md`. Local runtime paths and credentials from the previous PC are not dependencies of this repository.
