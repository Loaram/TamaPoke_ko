PC용 Chrome 또는 Edge에서 열어 주세요. 이 브라우저는 USB 연결을 지원하지 않습니다.

1한국어 펌웨어 설치

데이터 전송이 가능한 USB 케이블로 기기를 PC에 연결하세요. 아래 버튼을 누르고 연결된 포트를 선택합니다.

PC용 Chrome 또는 Edge가 필요합니다.HTTPS 또는 localhost에서 열어 주세요.

업데이트 설치 · 저장 데이터 유지
설치 창의 Erase device(기기 초기화)를 선택하지 않고 Next를 누르세요. 기존 포켓몬·도감·배지를 보존하도록 펌웨어 영역만 기록합니다.

처음 설치하거나 완전히 초기화하려면

새 기기는 그대로 설치하면 됩니다. 기존 데이터를 모두 지우려는 경우에만 Erase device를 선택하세요. 초기화하면 포켓몬·도감·설정이 삭제됩니다. microSD의 스프라이트 파일은 지워지지 않습니다.

연결할 포트가 보이지 않아요

BOOT를 누른 채 RESET을 한 번 누르고, BOOT에서 손을 떼세요. USB-C 옆의 작은 버튼입니다. 화면이 바뀌지 않아도 설치 버튼을 다시 눌러 포트를 확인하세요.

충전 전용 케이블은 사용할 수 없습니다. 데이터 케이블을 PC에 직접 연결하고, 다른 설치 창이나 시리얼 프로그램을 닫으세요.

설치 도구의 팝업은 영어로 표시됩니다. Install → Erase device 미선택 → Next 순서로 진행하세요. 중요한 세이브는 업데이트 전에 시리얼의 EXPORT 기능으로 백업하는 것이 좋습니다.

2스프라이트 설치

기기에 microSD를 넣고, 1단계 설치 창을 닫은 뒤 연결하세요. 원하는 지방만 설치해도 되고 나중에 추가할 수도 있습니다.

USB 전송은 시간이 걸립니다. 관동 팩은 약 10~15분이 걸릴 수 있어요. 전송 중에는 케이블과 SD 카드를 빼지 말고 이 페이지를 열어 두세요.

기기를 연결하면 설치할 지방을 선택할 수 있습니다.



직접 만든 스프라이트 파일 설치




3연결 해제 후 재시작
설치 완료 메시지를 확인한 뒤 연결 해제를 누르고 기기를 재시작하세요. 새 게임은 한국어로 시작합니다. 기존 세이브는 설정의 언어 버튼을 눌러 한국어로 바꿀 수 있습니다.


기존 별명과 저장 데이터는 그대로 유지됩니다. 이름 입력 키보드는 원본의 영문 키보드를 사용합니다.


4근거리 배틀


ESP32↔ESP32, 같은 Wi-Fi의 Android↔Android/Wear OS, ESP32가 만드는 Wi-Fi를 이용한 ESP32↔앱/워치 대전을 지원합니다.


ESP32와 Android 또는 워치 연결


    

  1. ESP32의 트레이너 메뉴에서 근거리 대전을 열고 방 만들기 또는 참가하기와 사용할 파티를 선택합니다.
    2. 

  2. ESP32 화면에 표시된 TamaPoke-XXXX Wi-Fi를 Android 또는 워치에서 선택합니다. 암호는 tamapoke입니다.
    3. 

  3. 인터넷이 없다는 안내가 나오면 연결 유지를 선택하고 TamaPoke로 돌아옵니다.
    4. 

  4. 앱이나 워치에서도 근거리 대전을 열고 방과 파티를 선택합니다. 상대 이름과 준비 완료가 나오면 전투를 시작합니다.
    5. 



앱 또는 워치끼리 연결


두 기기를 같은 Wi-Fi 공유기에 연결하고 양쪽에서 근거리 대전을 엽니다. 처음 사용할 때 로컬 네트워크 권한이 나오면 허용하세요. 상대 탐색에는 최대 약 90초가 걸릴 수 있습니다.


버전 확인: 새 기술 번호를 안전하게 주고받으려면 무선 프로토콜 4를 사용하는 ko.1.1.5 이상끼리 연결하세요. ko.1.1.6 사용을 권장합니다.


상대를 찾지 못할 때
공유기의 게스트 Wi-Fi나 AP 격리 기능, VPN, 방화벽, 배터리 절약이 로컬 통신을 막을 수 있습니다. 양쪽 모두 뒤로 나갔다가 같은 네트워크와 권한을 확인한 뒤 다시 시도하세요.




5세이브 이전


근거리 대전 화면에서 ESP32, Android와 Wear OS 사이에 포켓몬·파티·60칸 박스·도감·배지·설정을 복사할 수 있습니다. 원본 기기의 세이브는 자동으로 삭제되지 않습니다.


    

  1. 위의 근거리 배틀과 같은 방법으로 두 기기의 네트워크를 준비합니다.
    2. 

  2. 원본 기기는 세이브 보내기, 대상 기기는 세이브 받기를 누릅니다.
    3. 

  3. 양쪽 화면의 6자리 확인 코드가 같은지 확인합니다. 다르면 뒤로 나가 다시 연결합니다.
    4. 

  4. 진행률이 100%가 되고 대상 기기에 받기 완료가 나올 때까지 화면과 연결을 유지합니다.
    5. 

  5. 대상 기기에서 세이브 적용 → 예를 누릅니다. 받은 세이브로 교체한 뒤 앱 또는 기기가 재시작됩니다.
    6. 



안전 장치: 받기 완료만으로 기존 세이브는 바뀌지 않습니다. 모든 조각과 CRC16 검사가 성공하고 사용자가 마지막 적용을 확인해야 덮어씁니다. 전송이 끊기거나 손상되면 적용 버튼이 나오지 않습니다.

기본 조작
포켓몬을 눌러 쓰다듬고, 아래 아이콘으로 먹이·수면·목욕·훈련을 선택하세요. 이름을 누르면 메뉴가 열립니다. 오른쪽으로 밀면 파티, 왼쪽으로 밀면 체육관으로 이동합니다. PWR 버튼을 짧게 누르면 화면을 끄고, 길게 누르면 전원을 끕니다.
