1한국어 펌웨어 설치

데이터 전송이 가능한 USB 케이블로 기기를 PC에 연결하세요. 아래 버튼을 누르고 연결된 포트를 선택합니다.

PC용 Chrome 또는 Edge가 필요합니다.HTTPS 또는 localhost에서 열어 주세요.

업데이트 설치 · 저장 데이터 유지
설치 창의 Erase device(기기 초기화)를 선택하지 않고 Next를 누르세요. 기존 포켓몬·도감·배지를 보존하도록 펌웨어 영역만 기록합니다.

처음 설치하거나 완전히 초기화하려면

새 기기는 그대로 설치하면 됩니다. 기존 데이터를 모두 지우려는 경우에만 Erase device를 선택하세요. 초기화하면 포켓몬·도감·설정이 삭제됩니다. microSD의 스프라이트 파일은 지워지지 않습니다.

연결할 포트가 보이지 않아요

BOOT를 누른 채 RESET을 한 번 누르고, BOOT에서 손을 떼세요. USB-C 옆의 작은 버튼입니다. 화면이 바뀌지 않아도 설치 버튼을 다시 눌러 포트를 확인하세요.

충전 전용 케이블은 사용할 수 없습니다. 데이터 케이블을 PC에 직접 연결하고, 다른 설치 창이나 시리얼 프로그램을 닫으세요.

설치 도구의 팝업은 영어로 표시됩니다. Install → Erase device 미선택 → Next 순서로 진행하세요. 중요한 세이브는 업데이트 전에 시리얼의 EXPORT 기능으로 백업하는 것이 좋습니다.

2스프라이트 설치

기기에 microSD를 넣고, 1단계 설치 창을 닫은 뒤 연결하세요. 원하는 지방만 설치해도 되고 나중에 추가할 수도 있습니다.

USB 전송은 시간이 걸립니다. 관동 팩은 약 10~15분이 걸릴 수 있어요. 전송 중에는 케이블과 SD 카드를 빼지 말고 이 페이지를 열어 두세요.

기기를 연결하면 설치할 지방을 선택할 수 있습니다.



직접 만든 스프라이트 파일 설치




3연결 해제 후 재시작
설치 완료 메시지를 확인한 뒤 연결 해제를 누르고 기기를 재시작하세요. 새 게임은 한국어로 시작합니다. 기존 세이브는 설정의 언어 버튼을 눌러 한국어로 바꿀 수 있습니다.


기존 별명과 저장 데이터는 그대로 유지됩니다. 이름 입력 키보드는 원본의 영문 키보드를 사용합니다.


기본 조작
포켓몬을 눌러 쓰다듬고, 아래 아이콘으로 먹이·수면·목욕·훈련을 선택하세요. 이름을 누르면 메뉴가 열립니다. 오른쪽으로 밀면 파티, 왼쪽으로 밀면 체육관으로 이동합니다. PWR 버튼을 짧게 누르면 화면을 끄고, 길게 누르면 전원을 끕니다.
