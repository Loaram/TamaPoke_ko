# TamaPoke 한국어판 3.5.0

사용자 지정 버전 3.5.0입니다. 전체 세이브 복사와 별개로 파티·박스에서 한 마리를 보내거나 1:1 교환할 수 있습니다.

## 사용 방법

근거리 대전 → 포켓몬 전송 / 교환에서 시작합니다. 선물은 보내기 / 받기, 맞교환은 양쪽 모두 교환을 선택합니다. 보낼 포켓몬을 고른 뒤 상대 이름, 양쪽의 6자리 확인 코드, 보내기·받기 정보를 비교하고 양쪽 모두 확정하세요.

- Android·Wear끼리는 같은 Wi-Fi, ESP와 앱·워치는 ESP의 TamaPoke 방, ESP끼리는 기존 직접 무선 연결을 사용합니다. 인터넷 원격 교환은 지원하지 않습니다.
- 파티·박스 개체만 대상입니다. 현재 키우는 포켓몬은 먼저 보관하고 선택합니다. 알은 제외합니다.
- 보내기는 수신 측 파티 우선·박스 다음 빈칸으로 이동하며 완료 뒤 발신 측에서 제거됩니다. 맞교환은 내보내는 칸을 사용하므로 꽉 찬 박스에서도 가능합니다.
- 종·폼·레벨·이로치·개체값·훈련·기술·별명·개별 돌봄 상태를 보존합니다. 능력치를 재추첨하거나 통신 진화를 하지 않습니다.
- 받은 종과 이로치만 도감에 등록하며 중복 종은 한 번만 셉니다. 보내도 기존 도감은 유지합니다. 도감 보너스는 기존 계산에 따라 반영됩니다.
- 전송은 좋은 작별이 아니며 작별 횟수, 연속 기록, 배지, 설정을 넘기거나 초기화하지 않습니다. 기존 동료 보호와 성장·진화 규칙을 유지합니다.

## 중단과 복구

내가 확정하기 전에는 취소할 수 있습니다. 확정 이후에는 일방 취소하지 않고 같은 상대와 재연결해 마무리합니다. 앱 종료·재시작 후에도 거래 기록을 불러옵니다. 한쪽이 완료됐는데 상대가 대기 중이면 이전 거래 재연결을 이용하세요.

거래 중 보관 변경과 전체 세이브 백업·복원을 차단합니다. 시작 전에 백업하세요. 저장 오류는 앱 데이터나 SD를 지우지 말고 저장 공간과 원래 SD를 확인한 뒤 재시작하세요. 확인되지 않은 이전 완료 기록은 버리지 않으며, 최대 32건이 쌓이면 기존 상대와 재연결해 확인한 뒤 새 거래를 시작해야 합니다.

양쪽 모두 지원 버전을 사용해야 합니다. 데이터·기술·폼 호환과 수신 측 그림을 확인합니다. 거래 중 앱 삭제·초기화·다운그레이드는 하지 마세요. 상대 기기나 저장을 영구적으로 잃으면 자동 복구를 보장할 수 없습니다. 전체 백업의 고의 복원으로 만드는 복제까지 차단하는 서버 인증 기능은 없습니다.

## 기존 저장과 배포 파일

기존 저장 v7, 72바이트 포켓몬 기록, 300칸 박스, 무선 배틀 프로토콜 5, 전체 세이브 전송 규격을 유지합니다. 개체 거래는 별도 규격 1과 기기 로컬 복구 기록을 사용하며 복구 기록 자체는 다른 기기의 전체 세이브로 보내지 않습니다. 같은 서명키의 Android 3028 / Wear 3029 APK로 덮어설치하세요.

Android APK, Galaxy Watch4~9 Wear APK, ESP 설치 ZIP, 27쪽 한국어 플레이 가이드, 내용 변경 없는 워치 설치 가이드, SHA256SUMS.txt를 첨부합니다. 에뮬레이터·프로토콜·저장 오류 검사는 실제 기기 설치·기기 간 무선 시험을 대체하지 않습니다.
