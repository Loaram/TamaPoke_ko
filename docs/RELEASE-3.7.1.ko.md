# TamaPoke 3.7.1 — 워치 통신 버그 수정

폰끼리는 연결되지만 폰과 워치 사이의 근거리 대전·세이브 전송이 시작되지 않던 문제를 수정했습니다. 수정 테스트판에서 정상 작동한다는 사용자 확인을 받은 뒤 정식 배포합니다.

## 수정 내용

- 통신할 Wi-Fi 연결과 IPv4 주소를 확보한 뒤 연결을 시작합니다. 워치의 수신 필터 처리를 보완하고 인터넷 없는 ESP Wi-Fi 방도 배제하지 않습니다.
- 재시도 시 이전 연결을 새로 만들며 Wi-Fi 변경·권한 오류·상대 검색 실패를 구분해 안내합니다.
- 앱/워치 통신 화면에 IP·TX(보냄)·RX(받음)·E(마지막 송신/소켓 오류)를 표시합니다.
- 통신 종료·시간 초과·앱 백그라운드 이동 시 Wi-Fi 요청과 수신 필터 요청을 정리합니다.

## 업데이트 및 사용

- **앱을 삭제하지 말고 기존 앱 위에 업데이트 설치하세요.** Android 3042 / Wear 3043으로 테스트판과 정식 3.7.0에서 모두 업데이트할 수 있습니다.
- 폰과 워치를 같은 Wi-Fi에 실제로 연결하고 두 앱을 화면에 띄워 두세요. 워치가 폰에 블루투스로 연결된 것만으로는 충분하지 않습니다.
- 세이브 이전은 한쪽에서 보내기, 다른 쪽에서 받기를 선택합니다. 수신 뒤 적용하면 받는 기기의 기존 저장이 교체됩니다.
- ESP 업데이트에서 Erase device를 선택하지 말고 원래 microSD도 유지하세요.
- 저장 v7·개체 72바이트·세이브/대전/교환 통신 규칙과 게임 밸런스는 그대로입니다. 공용 활력과 탐색 비용 22도 유지합니다.

## 다운로드

- Android-Full-debug.apk: 스마트폰용.
- WearOS-GalaxyWatch4-9-debug.apk: 워치용 ARM32/ARM64 공용 APK.
- Watch-Installer-Windows.zip: 정식 3.7.1 워치 APK·ADB·7쪽 설명서를 동봉한 Windows 설치 도우미. 모두 압축을 풀고 실행하세요. 도우미 자체는 시험판입니다.
- ESP32-Web-Installer.zip: 실기용 펌웨어. 웹 설치 페이지도 갱신합니다.
- 플레이 가이드 29쪽, 기존 워치 수동 설치 가이드, 설치 도우미 가이드 7쪽을 모두 첨부합니다.

## 검증 범위

전체 62개 런타임 회귀 검사, Java 연결 처리 20개, ESP 저장장치 장애 10개, 설치 도우미 30개 검사를 수행합니다. 300칸 세이브 양방향 전송·패킷 손실·재시도와 기존 저장 호환도 확인합니다. APK 서명·ABI·그림 팩·ZIP과 PDF를 검증합니다.

사용자 확인은 해당 폰/워치 조합의 통신 문제 해결 보고이며 모든 워치 모델·최초 페어링·ESP 실기 통신 검증을 뜻하지는 않습니다. [검증 보고서](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.7.1/README.md)를 참고하세요.

신규 기능이나 밸런스 변경이 아닌 통신 버그 패치이므로 **3.7.1**로 올립니다.
