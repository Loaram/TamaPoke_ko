# TamaPoke 3.9.2 — ESP 교체 저장 안정화

기능·밸런스 변경 없는 버그패치입니다. Android·Wear OS·기존 원형 ESP용 파일과 설치/플레이 가이드를 제공합니다.

## 수정

- ESP에서 300칸 보관함을 저장할 때 동시에 만들던 약 22KB 검증 버퍼 2개를 제거하고 256바이트씩 모든 내용을 재읽어 비교합니다. 약 43KB의 일시 메모리를 절약합니다.
- 데려오기와 저장 복구 재시도 전에 현재/진화/도감/배틀 그림 캐시를 해제합니다. 저장 기록은 건드리지 않으며 필요한 그림은 다시 불러옵니다.
- 미완료 교체를 완료된 조작으로 처리하지 않습니다. 실제 SD 쓰기·읽기·해시·커밋 실패는 기존대로 차단하여 기록을 보호합니다.

## 확인한 범위와 한계

보고 순서는 히드런 → 무한다이노(무한다이맥스) → 탐색/포획 → 원래 포켓몬입니다. 두 방향·파티·박스 300번 칸과 돌봄/훈련/폼/공용 활력 보존을 모의 검사했습니다. 일반 메모리 조건에서는 기존 버전도 통과했습니다.

추가 큰 메모리 할당을 실패시키면 기존 ESP SD 검증이 실패하는 경로를 재현했으며 수정 후 같은 조건에서 통과했습니다. 짧은 읽기/쓰기, 첫·블록 경계·마지막 바이트 손상, 저장 선택자 기록 실패와 복구를 함께 검사합니다.

**보고 기기의 USB 로그를 확보하지 못했으므로 실제 증상의 유일한 원인이나 실기 해결 완료를 단정하지 않습니다.** 메모리 부담과 재시도 경로의 확인된 취약점을 수정한 패치입니다. 업데이트 후 같은 순서로 다시 확인해 주세요.

## 업데이트

세이브 v7, 72바이트 개체 기록, 무선 규격, SD 보관함 경로·형식, ESP 파티션과 게임 규칙은 바뀌지 않습니다. 업데이트 전 백업하고 앱 삭제·저장 초기화·SD 포맷은 하지 마세요. ESP는 기존 SD를 그대로 사용하고 설치 중 `Erase device`를 선택하지 마세요.

오류가 다시 나타나면 먼저 `다시 확인`을 누르세요. 계속되면 초기화하지 말고 기종·버전·교체한 포켓몬/폼·발생 순서를 알려주세요. 구분이 불확실한 기록은 자동으로 덮어쓰지 않습니다.
