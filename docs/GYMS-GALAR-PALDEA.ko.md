# 가라르·팔데아 체육관 — 3.0.0-beta.2

> **개발 당시 기록입니다.** 이 체육관은 정식 3.0.0에 포함되었습니다. 아래 미공개·버전 표시는 beta.2 당시 상태이며 현재 배포 내용은 [릴리스 안내](RELEASE-3.0.0.ko.md)를 확인하세요.

아직 공개하지 않은 작업 브랜치용입니다. 정식 설치 페이지와 릴리스는 2.0.2 그대로입니다. 폼체인지와 체육관 추가를 같은 3.0.0 기능 버전에 묶고, 테스트 빌드만 beta.1에서 beta.2로 올렸습니다.

## 플레이 방법

- 체육관 지방 선택에서 가라르 또는 팔데아를 선택합니다. 목록은 좌우로 넘깁니다.
- 가라르 목록 위쪽 **가라르 소드 / 가라르 실드** 제목을 누르면 코스가 바뀝니다. 그 아래 일반/랜덤 버튼과는 별개입니다.
- 가라르 배지 화면에서도 지방 제목을 누르면 두 코스의 배지를 확인할 수 있습니다.
- 기존과 같이 앞 상대를 이겨 다음 상대를 해금합니다. 일반/랜덤의 승리 기록은 별도로 유지합니다.
- 가라르의 공통 관장 여섯 명과 공통 본선 상대는 기록을 공유합니다. 채두와 어니언, 마쿠와와 멜론, 본선의 채두와 어니언은 각각 따로 이겨야 합니다.
- 배지 개수의 `/8`에는 실제 체육관 여덟 곳만 셉니다. 사천왕·본선·챔피언의 승리 표시는 각 목록에 별도로 남습니다.

## 추가한 상대

| 지방·코스 | 체육관 순서 | 이후 상대 |
|---|---|---|
| 가라르 소드 | 아킬 → 야청 → 순무 → 채두 → 포플러 → 마쿠와 → 두송 → 금랑 | 비트 난입전 → 야청 → 채두 → 금랑 → 단델 |
| 가라르 실드 | 아킬 → 야청 → 순무 → 어니언 → 포플러 → 멜론 → 두송 → 금랑 | 비트 난입전 → 야청 → 어니언 → 금랑 → 단델 |
| 팔데아 | 단풍 → 콜사 → 모야모 → 곤포 → 청목 → 라임 → 리파 → 그루샤 | 칠리 → 뽀삐 → 청목 → 팔자크 → 테사 |

첫 도전의 포켓몬 종과 레벨을 기준으로 구성했습니다. 가라르 체육관 에이스는 20·24·27·36·38·42·46·48레벨, 단델은 최고 65레벨입니다. 팔데아는 15·17·24·30·36·42·45·48레벨, 테사는 최고 62레벨입니다. 원작 팔데아는 순서를 자유롭게 고를 수 있지만 이 게임에서는 레벨 순서의 기존 체육관 해금 방식을 사용합니다.

가라르에는 사천왕이 없습니다. 목록의 마지막 다섯 경기는 비트 난입전과 챔피언컵 본선·챔피언전입니다. 마리·호브의 준결승 및 스토리 이벤트는 포함하지 않습니다. 단델은 원작에서 플레이어가 흥나숭을 선택한 경우의 **킬가르도·드래펄트·액스라이즈·두빅굴·에이스번·리자몽** 팀으로 고정했습니다. 현재 키우는 포켓몬을 바꿔도 상대 팀은 바뀌지 않습니다.

## 원작과 다른 전투 규칙

이번 추가는 TamaPoke의 체육관 콘텐츠 확장이지 원작 전투 시스템 전체 이식은 아닙니다.

- 기존 1대1 연속 교체 방식, 레벨 상한, 일반/랜덤 규칙과 육성 보상을 유지합니다. 금랑·라임도 더블배틀 대신 이 방식으로 싸웁니다.
- 상대 기술은 이 포크의 레벨별 기술표에서 정합니다. 원작의 개별 기술·특성·도구·날씨·관중 보너스까지 복제하지 않습니다.
- 다이맥스·거다이맥스 자동 발동, HP 배수, 다이맥스 기술은 추가하지 않습니다. 기존 지속형 폼 선택과는 별개입니다.
- **테라스탈은 이번 범위에 포함하지 않습니다.** 팔데아의 에이스도 본래 타입으로 싸웁니다. 예를 들어 단풍의 깜지곰은 노말, 콜사의 꼬지모는 바위, 모야모의 무우마직은 고스트입니다. 체육관 전문 타입과 모든 상대의 타입이 일치한다는 뜻이 아닙니다.
- 포플러의 가라르 또도가스, 비트의 가라르 날쌩마, 어니언의 가라르 데스마스, 멜론의 가라르 불비달마는 지원 중인 폼 그림·타입·종족값으로 등장합니다. 상대는 플레이어의 폼 해금 레벨 제한을 받지 않습니다.
- 청목의 춤추새는 파칙파칙스타일이며 전기/비행 타입으로 싸웁니다. 기존 기본 그림 팩에 들어 있는 파칙파칙스타일을 사용하고, 이 상대의 타입 보정만 전투 중 적용합니다. 플레이어 세이브·알·탐색·폼 해금 목록은 변경하지 않습니다.
- 라임의 스트린더는 로우한 모습의 공식 정지 일러스트를 사용합니다. 타입과 종족값은 하이한 모습과 동일합니다.

## 이미지와 수집 가능 여부

관장 18명(가라르의 버전별 관장 포함)과 테사의 목록 그림은 공식 소개 사이트 이미지 19개를 축소한 것입니다. 사천왕·비트·단델은 기존 문자 목록 방식으로 표시합니다.

석탄산·꼬치조·클레스퍼트라·꼬이밍고는 이 빌드에서 움직이는 그림이 없어 **같은 종의 공식 정지 일러스트**를 상대 전투에서만 표시합니다. 스트린더 로우한 모습도 공식 정지 그림입니다. 다른 종으로 대체하지 않았습니다. 이 전투용 그림 추가만으로 수집 제한을 풀지 않으므로 수집 가능 종수는 그대로입니다. 새 지방 배지는 기존 타입색 메달 방식으로 표시하며, 공식 배지 원화를 넣었다고 주장하지 않습니다.

원본 이미지와 출처·SHA-256은 `data/gyms/art/`에 있으며 `tools/gen_gym_art.py`로 오프라인 재생성할 수 있습니다. 공식 이미지의 권리는 Pokémon/Nintendo/Creatures/Game Freak에 있습니다. PMDCollab 그림의 CC BY-NC 라이선스와 혼동하지 마세요. 공식 이미지에 별도 재배포 허락을 받았다는 의미는 아닙니다.

## 세이브 호환

기존 7개 지방의 순서는 유지하고 가라르=7, 팔데아=8을 뒤에 추가합니다. 기존 `badgX`·`badhX` 짧은 배열은 앞부분을 그대로 읽고 새 지방은 0으로 시작합니다. 가라르 소드 코스의 승리 비트는 0~12, 실드 고유 상대 세 명은 13~15입니다. 타입·폼을 가진 상대 데이터는 플레이어 포켓몬 기록에 쓰지 않습니다. 기존 폼 베타의 세이브 v3와 전송 크기 상한을 유지합니다. 구버전으로 되돌리면 새 지방 기록을 보존한다고 보장하지 않으므로 먼저 세이브를 백업하세요.
