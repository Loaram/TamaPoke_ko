# TamaPoke 3.5.1

## 통신 메뉴 이름 정리

체육관 지방 선택 화면과 관장 목록 아래의 **근거리 대전** 버튼을 **통신 메뉴**로 바꾸고, 연결 메뉴 제목도 같은 이름으로 맞췄습니다. 대전뿐 아니라 전체 세이브 이전과 한 마리 보내기·받기·교환을 포함하는 메뉴임을 알기 쉽게 했습니다.

안쪽의 **근거리 대전: 방 만들기 / 참가하기**, **세이브 보내기 / 받기**, **포켓몬 전송 / 교환**은 그대로 사용할 수 있습니다. 버튼 위치·동작·전송 방식·밸런스는 바꾸지 않습니다. 대전 항목의 이름과 다른 언어 번역도 유지합니다.

문구만 정리하는 패치이므로 사용자 지정 버전 **3.5.1**입니다. Android versionCode 3030, Wear OS 3031이며 기존 앱을 삭제하지 않고 업데이트하세요. 저장 v7, 개체 72바이트, 배틀 규격 5, 포켓몬 거래 규격 1은 그대로라 3.5.0과 통신·세이브 호환을 유지합니다.

## 설치와 설명서

- Android APK, Galaxy Watch4-9용 Wear APK, ESP32 웹 설치 ZIP을 제공합니다.
- 플레이 가이드 27쪽의 메뉴 명칭과 관련 화면을 갱신하고 기존 워치 수동 설치 PDF도 변경 없이 동봉했습니다.
- [Windows 워치 설치 도우미](WATCH-INSTALLER-3.5.1.ko.md)는 정식 3.5.1 APK와 7쪽 PDF를 동봉합니다. 도우미는 실제 워치 설치 미검증 시험판입니다.
- `SHA256SUMS.txt`는 전체 자산의 검사값이며 `WATCH-INSTALLER-SHA256SUMS.txt`는 도우미 ZIP·PDF 전용 검사값입니다.

업데이트 전에 세이브를 백업하세요. 확정 후 미완료된 포켓몬 전송·교환은 같은 상대와 재연결해 양쪽 모두 끝내세요. 앱 삭제·데이터 초기화·강제 다운그레이드는 하지 마세요. ESP 업데이트는 기존 microSD를 유지하고 Erase device를 선택하지 마세요.

## 검증 범위

메뉴 이름·대전 이름 보존·다른 언어 유지 회귀 검사와 한국어 표시, 통신 UI, 세이브 전송·이전 저장 호환을 검사합니다. Android/Wear 서명·정렬·ABI·버전, ESP 빌드·NVS 보존 분할 이미지, 에뮬레이터 화면, PDF 렌더링과 배포 자산 검사값을 확인합니다. 실물 워치·휴대전화·ESP 간 무선 연결이나 기기 설치를 새로 시험한 것은 아닙니다.
