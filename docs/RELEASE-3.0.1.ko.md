# TamaPoke 3.0.1

박스에서 바로 놓아줄 수 있도록 조작 경로를 정리한 정식 패치입니다. 기존 기능의 작은 UI 오류 수정이므로 사용자 버전 규칙에 따라 마지막 번호를 올렸습니다.

## 수정한 내용

- **박스의 포켓몬을 누르면 항상 상세창을 엽니다.** `놓아주기 → 예`로 바로 정리할 수 있으며 파티를 거칠 필요가 없습니다.
- 파티에서 교체 대상을 먼저 골랐어도 박스 포켓몬을 누른 즉시 교체하지 않습니다. 상세창의 가운데 **교체** 버튼으로 확정합니다. 선택된 파티 대상이 없으면 기존 **파티로** 기능을 제공합니다.
- **데려오기**로 현재 키우는 포켓몬과 맞교환하는 기능은 유지합니다. 파티 포켓몬을 빈 박스 칸에 넣는 동작도 유지합니다.
- 놓아주기 확인창에서 스와이프하면 확인을 취소하고, 상세창에서 스와이프하면 박스 목록으로 돌아갑니다. 박스를 나갈 때 이전 교체/상세창 상태가 남지 않도록 했습니다.
- 보관 쓰기에 실패하면 놓아주기를 완료한 것처럼 화면을 닫지 않고 개체와 확인창을 유지합니다.

**파티/박스의 놓아주기는 하루 작별 3회와 별개이며 횟수를 차감하지 않습니다.** 다만 확인 후 떠나보낸 개체는 영구 삭제됩니다.

## 호환·다운로드

- 3.0.0과 같은 저장 v7/TFR3, 무선 프로토콜 5, 폼·기술 데이터를 사용합니다. 포켓몬·박스·작별 보너스 등 게임 밸런스는 변경하지 않습니다.
- Android APK(versionCode 3014), Wear OS 통합 APK(3015), ESP32 설치 ZIP을 함께 제공합니다.
- 박스 조작을 갱신한 **22쪽 한국어 플레이 가이드**와 내용이 동일한 **Galaxy Watch4~9 설치 가이드**를 첨부하고 두 PDF 모두 체크섬에 포함합니다.
- 비공개 `-dex`/`-shiny` 에뮬레이터는 따로 빌드하며 공개 자산에는 넣지 않습니다.

업데이트 전 전체 세이브를 백업하세요. ESP는 원래 SD를 유지하고 웹 설치에서 **Erase device를 선택하지 마세요**. 앱은 기존 설치 위에 업데이트하며 세이브 백업 없이 삭제하지 마세요.
