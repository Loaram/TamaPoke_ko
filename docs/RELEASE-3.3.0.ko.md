# TamaPoke 한국어판 3.3.0

탐색 포획 결과를 놓치지 않도록 별도의 확인창을 추가한 정식 업데이트입니다. 결과 확인 방식의 편의 개선이므로 마이너 버전 3.3.0으로 배포합니다.

## 탐색 결과 확인

- **포획 성공:** 포켓몬 이름·레벨과 실제 파티/박스 보관 위치를 표시합니다.
- **포획 실패:** 배틀에서는 승리했지만 포획 판정에 실패했음을 표시합니다.
- **탐색 종료:** 배틀 패배 시 포획 판정이 없었음을 안내합니다.
- **보관 오류:** 보관 완료를 확인하지 못한 저장 문제를 포획 실패와 구분합니다. 저장 공간과 ESP의 원래 microSD를 확인하고 재실행한 뒤 실제 보관 상태를 확인하세요.

결과창은 **확인** 버튼을 눌러야 닫히며 탐색 화면으로 돌아갑니다. 화면 밖 터치나 스와이프로 닫히지 않습니다. 마지막 기술을 고를 때의 연속 터치로 결과가 바로 사라지지 않도록 짧은 입력 보호도 적용합니다. 이미 확정된 결과를 다시 그리거나 확인해도 포획 판정·보관을 반복하지 않습니다.

기존에는 최대 6개의 전투 메시지를 저장하면서 화면에 4줄만 보여 주었기 때문에 마지막 포획 안내가 숨겨지고 터치 한 번에 함께 삭제될 수 있었습니다. 결과창을 독립시켜 이 경로를 제거했습니다.

## 기존 규칙과 저장

탐색 활력 30, 조우·포획 확률, 도감·연속 돌봄 알 보너스, 개체값·성장·작별·폼·기술 규칙은 그대로입니다. 저장 v7·무선 프로토콜 5와 기존 포켓몬/폼/기술 번호를 유지합니다.

업데이트 전에 전체 세이브를 백업하고 **앱을 삭제하거나 데이터를 지우지 말고 덮어설치**하세요. 기존 서명키를 유지했으며 Android versionCode는 3024, Wear는 3025입니다. 기기 간 연결은 양쪽을 같은 최신 버전으로 맞춰 주세요. ESP는 원래 microSD가 계속 필요하며 저장 유지 업데이트에서 Erase device를 선택하지 마세요.

## 첨부 파일

- Android Full APK: ARM64 / x86_64.
- Galaxy Watch4~9 Wear OS APK: ARM32 / ARM64 통합판.
- ESP32 Web Installer ZIP.
- 한국어 플레이 가이드 PDF: 25쪽. 기존 페이지 위치는 유지하고 마지막에 탐색 결과창 설명을 추가했습니다.
- Galaxy Watch4~9 설치 가이드 PDF: 기존 내용 그대로 동봉.
- SHA256SUMS.txt.

## 검증

51개 런타임 검사, SD 저장 실패 모의 검사 10개 및 Android·Wear·ESP32·PC 빌드를 확인합니다. 새 결과창은 파티/박스 성공, 실패, 패배, 저장 오류, 연속 터치·스와이프 차단, 반복 그리기의 중복 방지, 실제 마지막 턴에서의 진입과 확인 후 탐색 복귀를 검사합니다. 실제 기기 설치·기기 간 무선·물리적 SD 전원 차단 검사는 하지 않았습니다. [상세 검증 기록](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.3.0/README.md).
