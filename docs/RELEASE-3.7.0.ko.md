# TamaPoke 3.7.0

포획한 포켓몬을 반복해서 데려와 활력이 다시 채워지던 문제를 수정하고, 탐색 비용을 조정한 마이너 밸런스 패치입니다.

## 공용 활력

- 활력은 플레이어가 함께 쓰는 하나의 수치입니다. 파티·박스 동료를 데려오거나 새로 포획·전송받은 포켓몬을 키워도 교체 전 활력을 이어받습니다.
- 보관 개체의 예전 활력을 더하거나 평균 내지 않습니다. 업데이트 시 현재 키우는 자리의 저장된 활력을 그대로 사용합니다.
- 좋은/일반 작별 후 새 알을 받아도 활력은 초기화되지 않습니다. 새 게임이나 전체 초기화만 활력 80으로 시작합니다.
- 수면 회복은 기존처럼 분당 8, 최대 100입니다. 훈련 등에서 쓰는 활력도 같은 공용 수치입니다. 다른 돌봄 상태·성장·개체값·훈련·기술·유대는 개체별로 유지합니다.
- 교체 도중 저장이 중단되면 교체 시점의 공용 활력도 복구합니다. 이미 확인된 최신 진행은 그대로 보존합니다.

## 탐색 비용

정식판 탐색 1회 비용을 **30 → 22**로 조정했습니다. 일반·랜덤 모두 동일하며 시작할 때 한 번 차감합니다. 활력 100에서 회복 없이 최대 4회 탐색하면 12가 남습니다. 포획 성공 여부나 데려오기 반복으로 충전되지 않습니다.

도감 100종마다 볼 배율 +0.2, 포획률 3의 특별 보정, 조우·이로치·알 확률, 개체값 규칙은 변경하지 않았습니다.

## 설치 파일과 가이드

Android APK, Galaxy Watch4-9 Wear OS APK, ESP32 설치 ZIP을 제공합니다. [플레이 가이드](https://github.com/Loaram/TamaPoke_ko/releases/download/3.7.0/TamaPoke-3.7.0-Play-Guide-KO.pdf)에 탐색 비용·공용 활력·교체 규칙을 반영했습니다. 기존 워치 수동 설치 PDF와 Windows 설치 도우미 ZIP·7쪽 PDF도 함께 제공합니다. [ESP 웹 설치 페이지](https://loaram.github.io/TamaPoke_ko/)에서도 업데이트할 수 있습니다.

## 저장 호환과 검증

저장 v7, 개체 72바이트, 배틀 5 / 거래 1 및 기존 번호를 유지합니다. Android 3040 / Wear 3041입니다. 업데이트 전에 전체 세이브를 백업하고 미완료 전송·교환을 완료하세요. 앱을 삭제하지 말고 덮어 설치하세요. ESP는 원래 SD를 유지하고 Erase device를 선택하지 마세요.

활력 0~100을 가진 보관 개체의 202가지 파티·박스 교체, 실제 포획 성공·데려오기·재시작 반복, 탐색 비용 경계, 수면 회복, 전체 세이브 왕복과 저장 장애를 시뮬레이션했습니다. 전체 61개 회귀 검사와 빌드 증거는 [검증 보고서](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.7.0/README.md)에 기록합니다. 실제 휴대전화·워치·ESP 설치와 기기 간 전파 시험은 별도입니다.
