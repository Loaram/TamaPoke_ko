# TamaPoke 3.5.2

데려오기 버튼과 훈련값 되돌림을 수정한 정식 버그 패치입니다. 사용자 지정에 따라 3.5.2로 배포합니다.

## 수정 사항

- 파티·박스 뒤에 기술 습득 선택이 남아 있을 때 데려오기 탭이 숨겨진 배우지 않기로 전달되던 오류를 수정했습니다. 실제 기술창을 먼저 열고 별도의 입력으로 선택합니다. 훈련 등 다른 화면 뒤의 기술창도 입력을 받지 않습니다.
- 교체 저장 확인 과정에서 기술 습득·훈련값 보정이 일어나 정상 저장을 실패로 판단하던 경로를 제거했습니다.
- 미완료 교체 기록보다 최근의 온전한 개체 저장이 확인되면 그 훈련·성장·기술 진행을 유지합니다. 개체 구분이 모호하면 자동 덮어쓰기 대신 보호 화면에서 정지합니다.
- 새 교체 저장이 미완료인 동안 훈련·성장·보관 변경을 막고 저장 확인과 재시도 방법을 표시합니다. 진행 중인 통신과 보관 저장 오류도 데려오기 제한 이유를 안내합니다.
- 이미 저장된 훈련값은 재시작이나 추가 훈련으로 감소하지 않습니다. 현재 개체값별 훈련 상한은 새 보상에 그대로 적용합니다.

## 업데이트

기존 앱을 삭제하지 말고 APK를 덮어 설치하세요. ESP는 기존 SD를 유지하고 Erase device를 선택하지 마세요. 저장 v7, 개체 72바이트, 배틀 규격 5와 개체 거래 규격 1은 유지합니다. Android versionCode 3032 / Wear OS 3033입니다.

이미 사라진 훈련값을 임의로 추정 복원하지 않습니다. ‘교체 저장 확인 필요’가 계속 나오면 초기화하지 말고 저장 공간과 원래 SD를 확인한 후 문의하세요.

28쪽 플레이 가이드, 기존 Galaxy Watch4-9 수동 설치 가이드, 이번 Wear APK를 포함한 Windows 워치 설치 도우미와 7쪽 설명서를 함께 제공합니다. 실물 기기의 설치·통신·전원 차단 시험은 별도입니다.
