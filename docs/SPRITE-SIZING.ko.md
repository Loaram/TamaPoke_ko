# 포켓몬 표시 크기 조정 — 3.7.3

3.7.3은 승인된 비교 화면의 '축소 + 원본 최대 4배 제한'을 적용합니다. 게임의 능력치·성장·수집 잠금·저장 형식·폼 번호는 바꾸지 않습니다.

## 표시 규칙

투명 여백을 제거한 그림 영역에 종과 폼의 키를 참고한 완만한 크기 구간을 적용합니다. 실제 키를 그대로 축척하지는 않습니다. 작은 포켓몬도 워치에서 알아볼 수 있게 하면서 피츄·피카츄와 리자몽·잠만보 사이의 크기 차이를 유지합니다.

| 키 기준 | 홈의 기준 높이 | 파티·박스 최대 가로/세로 |
|---|---:|---:|
| 0.3m 이하 | 80px | 32px |
| 0.4m | 92px | 34px |
| 0.5~0.7m | 104px | 36px |
| 0.8~1.2m | 120px | 38px |
| 1.3m 이상 | 144px | 40px |

홈·도감·배틀 등 PMD 애니메이션은 원본 대비 최대 4배까지만 확대합니다. 위 숫자는 반드시 채우는 크기가 아니라 종별 기준이며, 가로 제한이나 원본 해상도 때문에 더 작아질 수 있습니다. 리자몽의 기본 동작 영역 29×29px은 116×116px, 잠만보 30×31px은 120×124px로 표시합니다. 피츄는 74×80px, 피카츄는 61×92px입니다. 원본이 작은 진화형은 다른 종보다 작아 보일 수 있으나 도트를 과하게 늘리지 않는 것을 우선합니다. 파티·박스의 32~40px 작은 아이콘은 기존 기준을 유지합니다.

가로가 넓으면 비율을 유지하며 폭 제한 안에 맞춥니다. 표는 실제 모든 프레임의 높이가 아니라 Idle 애니메이션 전체 영역을 맞추는 기준입니다. 날개를 접거나 몸을 숙이면 원래 동작대로 작아 보이며 프레임마다 확대율을 바꾸지 않습니다. 이동·먹기 등은 Idle의 배율을 기준으로 하되 큰 동작은 화면 안전 영역에 맞춥니다. 홈의 그림은 상태 안내 아래에 유지하며, 산책 중 원형 화면 가장자리에서 잘리지 않도록 표시 위치를 제한합니다. 작별 때 화면 밖으로 떠나는 연출은 유지합니다.

파티·박스의 일반 그림과 폼 그림에 같은 기준을 사용합니다. 가라르·알로라 나옹은 34px 영역에 맞추며 이름과 겹치지 않습니다. 이로치도 같은 규칙을 적용하고, 이로치 그림 미지원 폼은 기존과 같이 같은 폼의 일반 그림을 사용합니다.

예외: 현재 대여르의 기본 그림은 대열 전체가 아닌 PMD 단독 병사입니다. 대열의 키 3m로 확대하지 않도록 홈 기준 92px·목록 34px을 사용합니다. 원본 확대 제한도 적용합니다. 이는 화면용 예외이며 공식 키 데이터 자체를 수정한 것은 아닙니다.

## 데이터와 검증

전체 1,025종과 지원 폼 176개의 키를 [PokeAPI 원본 데이터](https://raw.githubusercontent.com/PokeAPI/pokeapi/master/data/v2/csv/pokemon.csv)에서 가져왔습니다. 원본 SHA-256과 폼별 데이터/기본 종 대체 여부는 `data/sprite_sizes.json`에 기록합니다. 타입만 바뀌는 폼 등 별도 레코드가 없는 경우 같은 종의 기본 키를 사용합니다. 표시는 `sprite_sizes.h`에 별도 보관하므로 저장되는 포켓몬 구조에 영향을 주지 않습니다.

그림이 있는 기본 982종과 폼 176개, 일반·이로치/기존 대체 경로를 합쳐 2,316개를 검사했습니다. 원래 그림이 없는 43종은 그대로 제외하고 잠금을 해제하지 않습니다. 그림이 있어도 진화 계열 때문에 수집이 잠긴 15종도 표시 검사에는 포함합니다. 따라서 수집 가능 967종과 표시 검사 982종은 서로 다른 수치입니다.

- `tools/gen_sprite_sizes.py`: 체크인한 데이터에서 표시용 키 표 재생성.
- `tools/audit_sprite_layout.py`: 전체 프레임·팔레트·투명 영역·화면별 경계·4배 상한 검사와 전종 비교 화면 생성. 결과는 로컬 `build/size-cap-patch/audit/`.
- `tools/test_runtime.py --only sprite_layout`: 실제 로더와 렌더러, 전체 썸네일, 세 종류 나옹 및 대표 애니메이션의 고정 배율 회귀 검사.

플랫폼별 실제 기기 화면과 프레임 속도 검증은 별도입니다. 빌드 및 자동 검사의 구체적인 실행 결과는 `docs/qa/3.7.3/README.md`에 기록합니다. 이전 전수검수 이력은 `docs/qa/3.7.2-sprite-size/README.md`에 보존합니다.
