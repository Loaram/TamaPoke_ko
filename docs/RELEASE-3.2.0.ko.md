# TamaPoke 한국어판 3.2.0

수집 가능한 도감의 달성률로 알 보너스를 받을 수 있습니다. 기존 연속 돌봄 보너스를 유지하면서 두 목표를 함께 달성하면 최대 확률이 기존의 1.5배가 됩니다. 밸런스 변경에 맞춰 마이너 버전 3.2.0으로 배포합니다.

## 알 보너스

| 달성한 목표 | 이로치 | 전설 등급 |
|---|---|---|
| 연속 돌봄 10일만 달성 | 10% | 14% |
| 도감 50%만 달성 | 10% | 14% |
| 연속 돌봄 10일 + 도감 50% | **15%** | **21%** |

- 현재 실제 수집 가능한 **982종 중 491종 등록**이 도감 목표입니다. 그림 미지원 43종은 분모와 분자 모두 제외합니다. 같은 종의 이로치·폼·중복 개체는 별도로 세지 않습니다.
- 연속 돌봄과 도감 진행도에 따라 점진적으로 증가합니다. 10일 및 50% 이후 각 보너스는 더 올라가지 않으며 두 목표를 모두 달성해야 최종 최대치가 됩니다.
- 연속 기록이 끊겨도 누적 도감 보너스는 남습니다. 보관·교체·놓아주기로 도감 등록이 줄어들지 않습니다.
- 트레이너 배지 화면에서 수집 진행도와 **다음 알의 이로치·전설 확률**을 확인할 수 있습니다.
- **전설은 기존대로 도감 25종 등록 이후 해금**됩니다. 위 표의 돌봄 단독 행은 도감 보너스 기여가 없는 경우의 비교이며, 실제 등록 0종에서 전설이 나온다는 뜻이 아닙니다. 지역에 후보가 없을 때의 낮은 등급 대체와 도망 직후 일반 알 제한도 유지합니다.
- 이미 생성된 알은 다시 추첨하지 않고 새로 생성되는 알부터 반영합니다. 탐색 조우·포획률, 성장·훈련·작별 횟수·유대/개체값 규칙은 바꾸지 않습니다.

## 업데이트와 저장

앱을 삭제하거나 데이터를 지우지 말고 기존 앱 위에 업데이트하세요. 먼저 세이브를 백업하는 것을 권장합니다. 서명키는 기존과 같으며 Android versionCode는 3022, Wear는 3023입니다.

기존 도감·연속 기록으로 새 보너스를 계산하므로 저장 형식을 변경하지 않습니다. 저장 v7·무선 프로토콜 5·기존 포켓몬/폼/기술 번호를 유지합니다. 3.1.1에서 수정한 소리·수면·연속 기록 복원도 포함합니다. 이전 버전에서 이미 초기화되어 덮어쓴 기록은 자동 복원하지 않습니다. 기기 간 세이브 이전은 양쪽 모두 최신 버전으로 맞춰 주세요.

ESP32도 같은 3.2.0으로 제공합니다. 기존 NVS 파티션과 SD 보관 방식을 유지하며 **microSD가 계속 필요**합니다. 저장 유지 업데이트는 설치 페이지의 분할 펌웨어를 사용하고 Erase device를 선택하지 마세요.

## 다운로드

- Android Full APK: ARM64 휴대전화 / x86_64 Android 에뮬레이터.
- Wear OS Galaxy Watch4~9 APK: ARM32/ARM64 통합판.
- ESP32 Web Installer ZIP.
- 한국어 플레이 가이드 PDF: 24쪽, 도감 보너스 규칙·실제 화면 포함.
- Galaxy Watch4~9 설치 가이드 PDF: 기존 내용 그대로 동봉.
- SHA256SUMS.txt: 위 다섯 파일의 검증 해시.

## 검증 범위

50개 런타임 검사, SD 저장 실패 모의 검사 10개, 한국어·폼·설치 페이지 검사와 Android·Wear·ESP32·PC 빌드를 확인했습니다. 도감 0~982종과 연속 0~12일의 모든 조합, 정확한 목표 확률, 단조 증가·상한, 그림 없는 종 제외, 중복 등록, 연속 단절, 저장 v7 왕복 이전, 기존 알 유지 및 한국어·영어 화면을 검사했습니다. 실제 기기 설치·기기 간 무선 시험·물리적 전원 차단 검사는 하지 않았습니다.
