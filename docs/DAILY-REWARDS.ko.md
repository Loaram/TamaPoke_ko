# 연속 돌봄·도감 알 보너스와 하루 작별 제한 — 3.2.0

## 두 가지 진행도가 알 보너스를 올립니다

플레이어의 **연속 돌봄 10일**과 **수집 가능한 도감 50%**가 각각 목표입니다. 한 목표만 달성하면 기존 최대인 이로치 10%·전설 14%, 둘 다 달성하면 1.5배인 이로치 15%·전설 21%입니다.

| 연속 돌봄 | 수집 가능 도감률 | 이로치 확률 | 전설 등급 확률 |
|---|---|---|---|
| 0~1일 | 0% | 약 2.08% (1/48) | 3% |
| 10일 이상 | 0% (돌봄 기여만) | 10% | 14% |
| 0~1일 | 50% 이상 | 10% | 14% |
| 5일 | 50% 이상 | 약 12.22% | 약 17.11% |
| 10일 이상 | 50% 이상 | **15%** | **21%** |

표는 보너스 계산 비교입니다. **실제 전설 추첨은 기존의 도감 25종 등록 조건을 충족해야 합니다.** 실제 등록 0종에서 전설이 나오는 뜻이 아닙니다. 지역에 해당 등급 후보가 없으면 낮은 등급으로 대체하고, 도망 직후 다음 알은 일반 등급으로 제한합니다.

### 도감 집계

- 현재 수집 가능 대상은 982종입니다. 그림 미지원으로 수집할 수 없는 43종은 분모·분자 모두 제외합니다.
- 등록한 수집 가능 종수 / 982가 달성률이며 **491종 등록부터 도감 목표 완료**입니다. 50%를 넘어도 도감 보너스가 더 올라가지는 않습니다.
- 이로치·폼·중복 개체는 같은 도감 번호로 한 번만 셉니다. 알에서 나오지 않아도 탐색 등으로 수집 가능한 종은 셉니다.
- 가지고 있는 마릿수가 아니라 누적 도감 등록입니다. 박스 교체·놓아주기·작별로 도감 보너스가 줄어들지 않습니다.
- 설치된 지방 팩을 지우거나 바꿔도 분모가 줄지 않습니다. 향후 수집 가능 종수가 달라지면 현재 빌드의 정확한 종수로 계산합니다.
- 트레이너 화면에서 수집 가능 등록 수/전체 수, 달성률, 다음에 생성될 알의 확률을 봅니다. 실제 추첨은 반올림한 화면 숫자가 아니라 정수 가중치를 사용합니다.

### 연속 돌봄은 기존 규칙 유지

먹이·목욕·쓰다듬기·훈련 등 실제 돌봄을 한 날짜를 하루 한 번 기록합니다. 앱만 켜 두거나 알만 두드리는 것은 제외합니다. 다시 데려온 동료를 돌봐도 됩니다.

0~1일차는 기본, 2~10일차는 기존과 같은 폭으로 증가합니다. 어제까지의 기록은 오늘 첫 돌봄 전에도 유효합니다. 돌보지 않은 날이 하루 통째로 지나면 연속 보너스만 사라지고 다음 돌봄부터 1일차입니다. **도감 보너스는 남습니다.** 판정 기준은 현지 날짜이며, 시간이 없는 경우에도 도감 보너스는 적용됩니다.

### 중간 구간의 정확한 계산

두 목표에 대한 진행도를 함께 보간합니다. 단순 합산 후 상한을 자르는 방식이 아니므로 한 목표가 미달인데 최종 최대치에 먼저 도달하지 않습니다.

- S = (유효 연속 일수 - 1) / 9, 단 0~1일은 0, 10일 이상은 1.
- D = 수집 가능 등록 종수 × 2 / 수집 가능 전체 종수, 최대 1.
- P = 기본 × (1-S)(1-D) + 단독 최대 × [S(1-D)+(1-S)D] + 합산 최대 × SD.
- 이로치의 기본/단독/합산은 1/48·10%·15%, 전설은 3%·14%·21%입니다.
- 실제 구현은 이로치 21,600칸, 전설 900칸 정수 추첨을 유지하며 마지막 소수 가중치를 내림합니다. 도감의 표시 퍼센트를 먼저 반올림하지 않습니다.

이미 정해진 알의 종류·이로치 여부는 다시 추첨하지 않습니다. 새로 생성되는 알부터 반영합니다. 탐색 조우·포획 확률, 유대·좋은 작별에 따른 희귀 가중치와 개체값 보너스는 변경하지 않습니다.

## 작별은 하루 합계 3회

**좋은 작별, 메뉴의 일반 작별, 현재 포켓몬 보내기**를 합쳐 하루 3회까지입니다. 확인 후 작별이 시작될 때 1회가 차감되고 기기의 현지 자정에 다시 3회가 됩니다. 창을 열었다 취소하는 것은 차감하지 않습니다.

메뉴의 `돌봄 마치기 (2/3)`은 **오늘 남은 횟수**입니다. 작별 확인창과 플레이어 카드에서도 남은 횟수를 확인할 수 있습니다. 0회이면 다음 날까지 현재 포켓몬을 돌보거나 파티·박스에서 교체해서 플레이할 수 있습니다.

파티·박스끼리의 이동, 현재 포켓몬과의 맞교환, 보관한 포켓몬 정리는 차감하지 않습니다. 방치로 도망가는 사건도 자발적 작별 횟수에 넣지 않습니다.

좋은 작별 자격은 기존 그대로 **일반 진화 계통의 최종진화 + 부화 후 실제로 누적된 성장 1,440분(73레벨)**입니다. 최종진화한 순간부터 24시간을 더 기다리는 뜻이 아니며, 선택형 폼 변경도 조건에 포함하지 않습니다.

## 저장과 기기 간 이전

좋은 작별을 마친 개체는 **파티 우선, 파티가 가득 차면 박스**에 보관합니다. 둘 다 가득 찼다면 보관 대상을 고르는 화면이 나오므로 자리를 정리해 주세요. 24시간이 되었다고 저절로 이동하는 것은 아니며 사용자가 좋은 작별을 선택해야 합니다.

기존 연속 돌봄 기록과 포켓몬은 유지하며, 예전 저장에는 첫 적용 시 작별 3회를 부여합니다. 이후 연속일수와 사용 횟수는 저장·재실행·ESP/Android/Wear 간 전체 세이브 전송에 함께 포함됩니다. 전송 형식은 v7이며 이전 v1~v6를 읽지만 **새 저장을 구버전 앱에 되돌리는 것은 지원하지 않습니다**. 송수신 기기를 같은 최신 버전으로 맞춰 주세요.

시계를 뒤로 돌리거나 시간이 없는 상태로 재시작해도 사용 횟수는 충전되지 않습니다. 시간이 없을 때는 우선 3회까지만 가능하며, 정상 날짜를 설정해야 날짜별 초기화를 사용할 수 있습니다. 다만 서버 없는 게임이므로 과거 백업 복원이나 임의의 미래 날짜 설정까지 완전히 막는 기능은 아닙니다.

## 50페이지 박스를 빠르게 이동하기

- 박스 아래쪽 **`<` / `>` 버튼**으로 이전·다음 페이지를 넘깁니다. 첫 페이지의 이전, 마지막 페이지의 다음 버튼은 더 넘어가지 않습니다.
- 가운데 **`1/50` 같은 페이지 번호**를 누르면 페이지 선택창이 열립니다. 10페이지씩 묶어 표시하며 아래 화살표로 `1~10`, `11~20`, …, `41~50` 묶음을 옮깁니다. 원하는 번호를 누르면 해당 페이지로 바로 갑니다.
- 선택창의 돌아가기나 세로 스와이프는 선택창만 닫고 원래 박스로 돌아갑니다. 가로 스와이프는 선택창의 묶음을 넘깁니다.
- 기존 박스 가로 스와이프도 유지합니다. 파티와 교환할 대상을 고르는 중에도 버튼과 페이지 선택창을 사용할 수 있습니다. 페이지 이동 자체는 포켓몬을 옮기거나 작별 횟수를 차감하지 않습니다.

3.2.0 플레이 가이드 21쪽에 위 규칙과 트레이너 화면을 반영했습니다.
