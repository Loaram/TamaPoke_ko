# 연속 돌봄 보너스·하루 작별 제한·박스 이동 — 3.0.0

## 매일 돌봐 주면 알 보너스가 올라갑니다

포켓몬이 아니라 **플레이어의 연속 돌봄 일수**를 기준으로 합니다. 먹이 주기·씻기·쓰다듬기·훈련 등 실제 돌봄을 하루 한 번 하면 그날이 기록됩니다. 앱을 켜 두기만 하거나 알만 두드리는 것은 포함되지 않습니다. 성장 중인 포켓몬뿐 아니라 다시 데려온 동료를 돌봐도 됩니다.

- 같은 날 여러 번 돌봐도 하루만 인정합니다. 파티·박스 교체나 작별은 연속일수를 초기화하지 않습니다.
- 1일차는 기본 확률로 시작하고, 2~10일차에는 매일 같은 폭으로 확률이 올라갑니다. 10일 이후에는 상한을 유지합니다.
- 어제까지 이어 온 보너스는 오늘 첫 돌봄 전에도 유지됩니다. 돌보지 않은 날이 하루 통째로 지나면 기본 확률로 돌아가며, 다음 돌봄부터 1일차입니다.
- 판정 기준은 기기의 현지 날짜입니다. 시계가 설정되지 않은 ESP에서는 먼저 시간을 맞춰 주세요.

| 연속 돌봄 | 알의 이로치 확률 | 전설 등급 추첨 확률 |
|---|---:|---:|
| 기록 없음 / 1일차 | 약 2.08% (1/48) | 3.00% |
| 2일차 | 약 2.96% | 약 4.22% |
| 3일차 | 약 3.84% | 약 5.44% |
| 4일차 | 약 4.72% | 약 6.67% |
| 5일차 | 약 5.60% | 약 7.89% |
| 6일차 | 약 6.48% | 약 9.11% |
| 7일차 | 약 7.36% | 약 10.33% |
| 8일차 | 약 8.24% | 약 11.56% |
| 9일차 | 약 9.12% | 약 12.78% |
| 10일차 이상 | **10.00%** | **14.00%** |

10일차는 기존에 좋은 작별과 최대 돌봄 보너스를 모두 받았을 때의 실제 최대치입니다. 위 두 확률은 개체의 유대나 좋은 작별 여부로 더 올라가지 않습니다.

**전설 등급 추첨은 도감에 25종 이상 등록한 뒤부터** 적용됩니다. 첫 시작 포켓몬 선택에는 적용되지 않습니다. 선택한 지역에 등장 가능한 전설이 없으면 낮은 등급으로 대체되므로 표가 모든 지역에서의 전설 부화 확률을 보장하지는 않습니다. 방치로 도망간 뒤의 다음 알은 기존처럼 일반 등급만 등장합니다.

이 변경은 알의 이로치·전설 보너스에만 적용됩니다. 탐색 조우·포획 확률은 그대로이며, 희귀 등급의 좋은 작별/돌봄 가중치와 개체값 보너스도 유지합니다. 이미 생긴 알의 종류와 이로치 여부는 다시 추첨하지 않습니다.

## 작별은 하루 합계 3회

**좋은 작별, 메뉴의 일반 작별, 현재 포켓몬 보내기**를 합쳐 하루 3회까지입니다. 확인 후 작별이 시작될 때 1회가 차감되고 기기의 현지 자정에 다시 3회가 됩니다. 창을 열었다 취소하는 것은 차감하지 않습니다.

메뉴의 `돌봄 마치기 (2/3)`은 **오늘 남은 횟수**입니다. 작별 확인창과 플레이어 카드에서도 남은 횟수를 확인할 수 있습니다. 0회이면 다음 날까지 현재 포켓몬을 돌보거나 파티·박스에서 교체해서 플레이할 수 있습니다.

파티·박스끼리의 이동, 현재 포켓몬과의 맞교환, 보관한 포켓몬 정리는 차감하지 않습니다. 방치로 도망가는 사건도 자발적 작별 횟수에 넣지 않습니다.

좋은 작별 자격은 기존 그대로 **일반 진화 계통의 최종진화 + 부화 후 실제로 누적된 성장 1,440분(73레벨)**입니다. 최종진화한 순간부터 24시간을 더 기다리는 뜻이 아니며, 선택형 폼 변경도 조건에 포함하지 않습니다.

## 저장과 기기 간 이전

좋은 작별을 마친 개체는 **파티 우선, 파티가 가득 차면 박스**에 보관합니다. 둘 다 가득 찼다면 보관 대상을 고르는 화면이 나오므로 자리를 정리해 주세요. 24시간이 되었다고 저절로 이동하는 것은 아니며 사용자가 좋은 작별을 선택해야 합니다.

기존 연속 돌봄 기록과 포켓몬은 유지하며, 예전 저장에는 첫 적용 시 작별 3회를 부여합니다. 이후 연속일수와 사용 횟수는 저장·재실행·ESP/Android/Wear 간 전체 세이브 전송에 함께 포함됩니다. 전송 형식은 v7이며 이전 v1~v6를 읽지만 **새 저장을 구버전 앱에 되돌리는 것은 지원하지 않습니다**. 송수신 기기를 같은 최신 버전으로 맞춰 주세요.

시계를 뒤로 돌리거나 시간이 없는 상태로 재시작해도 사용 횟수는 충전되지 않습니다. 시간이 없을 때는 우선 3회까지만 가능하며, 정상 날짜를 설정해야 날짜별 초기화를 사용할 수 있습니다. 다만 서버 없는 게임이므로 과거 백업 복원이나 임의의 미래 날짜 설정까지 완전히 막는 기능은 아닙니다.

## 50페이지 박스를 빠르게 이동하기

- 박스 아래쪽 **`<` / `>` 버튼**으로 이전·다음 페이지를 넘깁니다. 첫 페이지의 이전, 마지막 페이지의 다음 버튼은 더 넘어가지 않습니다.
- 가운데 **`1/50` 같은 페이지 번호**를 누르면 페이지 선택창이 열립니다. 10페이지씩 묶어 표시하며 아래 화살표로 `1~10`, `11~20`, …, `41~50` 묶음을 옮깁니다. 원하는 번호를 누르면 해당 페이지로 바로 갑니다.
- 선택창의 돌아가기나 세로 스와이프는 선택창만 닫고 원래 박스로 돌아갑니다. 가로 스와이프는 선택창의 묶음을 넘깁니다.
- 기존 박스 가로 스와이프도 유지합니다. 파티와 교환할 대상을 고르는 중에도 버튼과 페이지 선택창을 사용할 수 있습니다. 페이지 이동 자체는 포켓몬을 옮기거나 작별 횟수를 차감하지 않습니다.
