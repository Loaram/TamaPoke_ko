# TamaPoke 3.9.0 — 인게임 세이브 초기화

편의 기능 추가이므로 사용자 버전 정책에 따라 3.9.0입니다. 기존 플레이·포획·성장 규칙, 저장 v7·개체 72바이트·무선 규격은 변경하지 않습니다. Android 3052 / Wear 3053.

## 새 게임 시작

설정 → 세이브 초기화 → 다음 → 모두 지우고 새로 시작. 마지막 확인 후 1초 동안 삭제 입력을 받지 않아 연속 터치로 실수하는 일을 줄입니다. 취소하면 저장을 변경하지 않습니다.

- 현재 포켓몬·파티·박스·도감·배지·메달·트레이너·훈련·연속기록·알 수령 기록 초기화.
- 소리·음량·언어·기기 시계·지방/폼 그림 팩 유지. 외부 백업은 삭제하지 않습니다.
- 대전·전송·미완료 교환·보관 복구 중 초기화 차단. 상대가 미수신한 교환 완료를 복구하는 내부 증명은 유지합니다.
- 초기화 의도를 먼저 저장한 뒤 각 게임 기록을 지우고 완료를 확인합니다. 중단된 초기화는 부팅 시 먼저 복구하며, 실패 중에는 플레이·자동저장을 차단합니다.
- ESP는 재시작하며 Android·Wear·PC는 앱 종료 후 다시 열어야 합니다. SD의 옛 박스 저장본은 자동으로 불러오지 않습니다. 복구 불가능한 보안 삭제를 보장하는 기능은 아닙니다.

**업데이트 시에는 기존 앱 위에 설치하고, ESP의 Erase device는 선택하지 마세요. 초기화는 모든 진행을 지울 때만 직접 선택하세요. 실행 취소가 없으므로 필요한 세이브는 먼저 백업하세요.**

## 동봉 파일과 검증

Android·Wear APK, ESP 설치 ZIP, 30쪽 플레이 가이드, 기존 Watch4–9 수동 설치 PDF, 이번 APK를 동봉한 Windows 워치 설치 도우미와 7쪽 설명서를 제공합니다.

검사 범위: 초기화 확인/취소/연속 입력, 통신 차단, 모든 저장 변경 단계에서 중단 후 복구, 저장 실패와 재시도, Android 종료/복귀 자동저장, 실제 파일 재읽기와 기존 회귀 검사. 상세 결과는 docs/qa/3.9.0에 기록합니다. 이번 실제 기기 초기화·물리 전원 차단은 미검증이며 사용자 기기를 임의로 초기화하지 않습니다.
