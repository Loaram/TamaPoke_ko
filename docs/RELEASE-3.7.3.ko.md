# 3.7.3 - 원본 그림 최대 4배 확대 제한

작은 원본 그림이 지나치게 확대되어 도트가 거칠게 보이던 현상을 줄였습니다. 사용자가 승인한 '크기 축소 + 원본 4배 제한' 비교안을 적용하는 표시 패치입니다.

- 홈 기준 높이를 80/92/104/120/144px로 조정했습니다. 실제 크기는 그림 비율과 원본 해상도에 따라 더 작아질 수 있습니다.
- 홈·도감·배틀 등의 기본/폼/이로치 PMD 애니메이션은 원본의 가로·세로 각각 최대 4배까지만 확대합니다.
- 전체 동작의 그림 영역을 기준으로 배율을 고정해 프레임마다 커졌다 작아지지 않습니다. 원형 화면과 상태 문구의 안전 영역도 유지합니다.
- 리자몽은 기본 동작 기준 168×168 → 116×116px, 잠만보는 163×168 → 120×124px입니다.
- 파티·박스의 읽기 쉬운 32~40px 아이콘 기준, 3.7.2의 유대 수정은 유지합니다. 그림 팩을 새로 설치할 필요는 없습니다.

저장 v7·개체 72바이트·도감/폼/기술 번호·통신·게임 밸런스는 변경하지 않습니다. 앱을 삭제하지 말고 기존 앱 위에 업데이트하세요. Android versionCode 3046 / Wear 3047입니다. ESP 사용자는 Erase device 없이 업데이트하고 SD를 유지하세요.

정식 배포에는 폰/워치 APK, ESP 설치 ZIP, Windows 워치 설치 도우미, 최신 플레이 가이드와 설치 PDF를 함께 제공합니다. 기존 수동 워치 설치 PDF는 원본 그대로 동봉합니다. [설치 페이지](https://loaram.github.io/TamaPoke_ko/)와 메인 저장소도 함께 갱신합니다.

전체 그림 2,316개 경로·112,549프레임·74,188개 액션/표시 영역의 상한을 검사하고 승인 비교안 1,158개와 대조합니다. 최종 64개 런타임 회귀·통신·SD 저장·ESP 서버 빌드를 공개 전 필수 조건으로 사용합니다. 실제 폰·워치·ESP 설치와 프레임 속도는 이번 작업에서 미검증입니다.
