# 3.5.2 검증

버그 재현: 파티/박스 뒤의 기술 습득 큐가 데려오기 입력을 받음. 별도로 미완료 교체 저널이 후속 교체를 막고 재시작에서 나중 훈련값을 되돌림.

수정: 표시 중인 기술창만 입력 처리, 데려오기에서 실제 선택창 안내, 게임 진행을 수행하지 않는 저장 검증, 최신 일관된 개체 저장 보존, 모호한 개체 구분 시 쓰기 중단, 미완료 교체 시 진행 잠금과 재시도, 기저 훈련 보존.

`swap_recovery_test.cpp`는 자연 레벨업, 파티/박스, 7가지 개체 저장 키 실패, 재시도, 기존 저널 + 새 훈련 12/23/34 → 22/33/44, 재시작 반복, 같은 식별값의 모호한 개체를 검사합니다. 재현에는 가상 저장만 사용했으며 사용자 세이브에는 접근하지 않았습니다.

저장/개체/통신 규격은 바뀌지 않습니다. 실제 기기 검증은 미수행입니다. 전체 검사와 빌드 결과는 이 폴더의 최종 기록을 참조하세요.

로컬 핵심 8개 검사, 추가 박스 정렬/다시 데려오기 2개, SD 저장 실패 10개와 설치 도우미 30개를 통과했습니다. 전체 실행은 Windows WinError 4551로 i18n 실행에서 중단되어 보안 설정 변경 없이 GitHub CI를 사용합니다. 나머지 실행 중 박스 정렬의 기존 `writable()==true` 기대는 새 전체 보관 잠금 규칙에 맞춰 `false`로 수정했고 재실행을 통과했습니다.

최종 APK 2개는 기존 서명과 패키지를 유지합니다. Android ARM64/x86_64, Wear ARM32/ARM64 및 ESP, 일반 에뮬레이터와 로컬 전용 도감 2종을 빌드했습니다. 공개 파일 9개의 해시, 팩 일치, 워치 도우미에 들어간 APK/PDF 일치, 플레이 28쪽/도우미 7쪽과 기존 수동 설치 PDF의 동일성을 검사했습니다. 두 갱신 PDF를 전 페이지 렌더링하여 확인했습니다.
