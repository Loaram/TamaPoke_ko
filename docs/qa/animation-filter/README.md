# 정지 폼 제외 — beta.4 검증

사용자가 **폼체인지에만 적용하고 체육관은 유지**하도록 선택했습니다. 기존 179개 폼의 일반/이로치 350개 파일을 실제 픽셀 프레임 단위로 검사해, 동작 전체가 정지 그림뿐인 폼 3개(그림 6개)를 제외했습니다.

| 제외 폼 | 저장 번호 | 검사 결과 |
|---|---:|---|
| 거다이맥스 리자몽 | 10365 | 일반·이로치 모두 대기 한 프레임만 존재 |
| 메가치렁 | 10531 | 일반·이로치 모두 대기 한 프레임만 존재 |
| 거다이맥스 마휘핑 | 10392 | 일반·이로치 모두 대기 한 프레임만 존재 |

- 남은 176개 폼, 344개 일반/이로치 파일은 모두 실제 다른 픽셀 프레임이 있는 동작을 갖습니다.
- 대기 자세만 정지인 4개 폼은 다른 동작이 움직이므로 유지합니다. 무한다이맥스는 애니메이션이 있어 유지합니다.
- 기존 제외 폼의 저장 번호와 개체 정보는 유지하고 그림·타입·능력치는 기본 모습으로 표시합니다. 예전 파일이 SD에 남아 있어도 로더가 그 정지 파일을 사용하지 않는지 검사합니다.
- 체육관 표와 공식 이미지 헤더의 해시가 beta.3 기록과 같은지 확인합니다. 체육관 공식 정지 그림은 의도적으로 유지합니다.
- 공통 코드 38개 회귀 테스트 및 폼 UI·기존 저장·자유 교체·신규 체육관 집중 테스트를 실행합니다.
- PC·Android arm64/x86_64·Wear OS armv7/arm64·ESP32-S3를 빌드하고 양쪽 APK의 폼 팩이 새 344개 팩과 일치하는지 확인합니다.
- 프로토콜 5/세이브 v4/TFR2는 유지하지만 폼 데이터 식별값은 32462로 변경했습니다. 대전할 기기 양쪽을 같은 베타로 맞춰야 합니다.

완료 로그와 SHA-256은 `tools/record_animation_qa.py`가 검증한 뒤 `build-results.json`에 기록합니다. 실제 기기 설치·터치·무선 검증 및 공개 업로드는 하지 않았습니다. 이전 `forms-runtime`, `gyms`, `active-swap` 빌드는 각각 이전 베타의 기록으로 보존합니다.
