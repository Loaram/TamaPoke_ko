# 2.0.0 검사·빌드 기록

기록일: 2026-09-05

## 포함 변경

- 탐색을 정식 기능으로 승격. 일반은 현재 포켓몬 레벨 ±5, 랜덤은 레벨 1~100.
- 탐색 1회당 활력 30, 조우 종류는 일반 70%·진화 22%·희귀 7%·전설 1%.
- 승리 뒤 몬스터볼 1배·HP 10%·상태이상 없음 기준으로 자동 포획 1회. 포획률 3은 2.5% 고정.
- 현재 포켓몬 1마리와 보관 파티 5마리로 전투 후보 최대 6마리. 구버전 여섯 번째 파티원은 박스로 이전.
- 미라이돈 로우파워폼, 모으령 로밍폼 등 대체 폼 그림 5종을 사용해 관련 알·탐색 잠금 해제.
- Android·Wear OS의 고정 87% 배터리를 실제 기기 잔량·충전 상태 연동으로 교체.
- 버전 이름과 태그에서 `ko.` 접두어를 제거하고 `2.0.0`부터 숫자만 사용.

## 자동 검사

- 한국어 글꼴·문자열 검사: 789자, 14,202바이트, 7개 언어 × 193개 UI 문자열 통과.
- 런타임 32개 묶음 통과: 세이브/구버전 변환, 무선 프로토콜, LAN, 전투, 전체 기술표, 진화, 파티·60칸 박스, 스프라이트, 터치·넘기기, 탐색·포획.
- 도감 1~1025 전체 접근, 그림 982종 로드, 대체 폼 일반·이로치 그림과 썸네일 검사 통과.
- 웹 설치기 NVS 보호, 9개 지역 TPAK, manifest와 펌웨어 해시 검사 통과.
- 18쪽 플레이 가이드를 A4 PNG 18장으로 다시 렌더링해 한글·표·이미지·쪽 번호를 확인.

## 비공개 테스트 빌드

- `TamaPoke-2.0.0-shiny.exe`: 일반·이로치 도감 완성판.

## 아직 필요한 실기 확인

ESP32의 실제 화면·터치·전원·SD·소리와 Android/Wear OS의 실제 배터리 반영, 기기별 탐색·포획 저장, ESP32↔앱/워치 LAN 대전·세이브 전송은 자동 검사로 대체할 수 없으므로 미확인 상태로 남깁니다.
