## 수정 사항

- Android·Wear OS에서 받은 세이브를 적용한 뒤 종료 직전 기존 포켓몬 상태로 덮어쓰던 문제를 수정했습니다. 적용한 프레임의 자동저장과 이후 종료 콜백을 모두 차단합니다.
- 야생 포켓몬의 이로치 도감 등록이 현재 키우는 포켓몬의 색상에 영향을 받던 문제를 수정했습니다.
- 영구 동료가 앱 종료 후 경과 시간을 반영할 때 레벨업하던 문제를 수정했습니다.
- Android·Wear OS에서 백그라운드 복귀 시 앱 종료와 같은 오프라인 성장·돌봄 규칙을 적용합니다. 방치 실수를 추가하지 않고 깨어 있는 포켓몬의 돌봄 수치에는 15의 하한 보호를 적용합니다. 이미 15 미만이던 수치를 15로 회복시키는 규칙은 아닙니다.
- Android·Wear OS가 앱 프로세스 시작마다 동일한 테스트용 난수 순서로 시작하던 문제를 수정했습니다. 기기의 난수 생성 기능을 사용합니다. 정상적인 무작위 추첨에서도 같은 포켓몬이 반복될 수 있으며 중복을 강제로 제외하지 않습니다.

## 업데이트와 세이브

- 2.0.0의 저장 형식과 무선 프로토콜 4를 유지합니다. 기존 세이브를 사용할 수 있습니다.
- APK는 기존 앱을 삭제하지 않고 덮어설치하세요. Android versionCode 2002, Wear OS versionCode 2003이며 2.0.0과 같은 서명 키를 사용합니다.
- ESP32는 설치 페이지에서 **Erase device를 선택하지 않고** 업데이트하세요.
- 세이브 수신 후 적용하면 ESP32는 재시작합니다. Android·워치는 앱이 닫히면 직접 다시 열어 받은 포켓몬·파티·박스·도감·배지를 확인하세요.
- 이미 잘못 등록된 도감 기록이나 이미 변한 레벨은 진위를 판별할 기록이 없으므로 자동으로 되돌리지 않습니다.
