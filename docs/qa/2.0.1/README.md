# 2.0.1 검사·빌드 기록

기록일: 2026-09-05

## 수정 및 재현 검사

- 수신 세이브 덮어쓰기: Android의 종료 요청 이후 pause/stop/resume/exit 콜백이 기존 Pet을 저장하지 않도록 검사합니다. 수신한 NVS 전체 키를 비교하고, 재로드 후 포켓몬·이로치·배지·파티·박스를 확인합니다. 스케치에서도 적용 직후 프레임을 끝내 자동저장 경로에 도달하지 않게 합니다.
- 야생 이로치 등록: 일반 파트너로 이로치 포획, 이로치 파트너로 일반 포획, 기존 이로치 등록 보존 및 재로드를 확인합니다.
- 영구 동료: 60레벨 동료가 종료 후 1시간 및 백그라운드 복귀 후에도 60레벨인지 확인합니다.
- 백그라운드: 2시간 경과 후 완전 종료와 같은 성장·포만감·청결·돌봄 실수를 확인하며 반복 콜백과 시계 역행을 검사합니다.
- 난수: 2.0.0 Android는 고정된 g_seed와 에뮬레이터 난수를 사용했습니다. 프로세스 재시작이 동일한 순서를 재생할 수 있으나 휴식 자체는 초기화하지 않습니다. 실제 Android 빌드에서 arc4random_uniform 동적 심볼 연결을 확인했습니다. ESP32 난수는 변경하지 않습니다.

## 빌드·자료

- 한국어 789글자, 193개 UI 문자열, 1,025종·695개 실제 기술 이름/데이터 검사 통과.
- 런타임 33개 묶음 통과. 신규 검사: `tools/emu/tests/android_lifecycle_test.cpp`, 추가 이로치 검사: `wild_test.cpp`.
- ESP32 스케치 2,142,535바이트(68%), 전역 RAM 83,988바이트(25%), 앱 2,142,688바이트. NVS/FFat 비침범 검사 통과.
- Android versionCode 2002, 303,453,414바이트, ARM64/x86_64.
- Wear OS versionCode 2003, 303,088,875바이트, ARM32/ARM64.
- APK 서명·정렬을 검사했으며 2.0.0과 같은 서명 키를 사용합니다.
- 18쪽 플레이 가이드의 버전, 오프라인 규칙, 세이브 적용 후 앱 다시 열기 안내를 갱신하고 모든 페이지를 PNG로 렌더링해 확인했습니다. 기존 Galaxy Watch4~9 설치 가이드는 변경하지 않습니다.
- `tools/package_release.py --guide-images <렌더링 폴더>`로 공개 APK 2개·ESP ZIP·PDF 2개와 SHA256SUMS를 조립합니다. `tools/prepare_release_guides.py`도 필수 확인 단계로 실행합니다.
- 비공개 2.0.1-dex 및 2.0.1-shiny 에뮬레이터를 빌드하되 공개하지 않습니다.
- GitHub의 새 검사 환경에는 추출된 스프라이트가 없으므로 런타임 검사 전에 `tools/unpack_sprites.py`를 실행하도록 준비 단계를 보완했습니다. 이는 배포 바이너리 변경이 아닙니다.

## 한계

이 검사는 실제 Android·워치·ESP32 무선 환경과 OS 종료 타이밍을 완전히 대체하지 않습니다. 실제 기기간 수신 후 재실행, 장시간 백그라운드 및 반복 조우에 대한 사용자 재확인이 필요합니다. 이미 발생한 레벨 상승과 잘못된 도감 기록은 자동 복구하지 않습니다.
