# 3.7.3 그림 확대 상한 패치 검수

승인한 비교안인 홈 크기 80·92·104·120·144px와 애니메이션 원본 최대 4배 확대를 적용했습니다. 파티·박스 아이콘 기준은 유지합니다. 능력치·확률·저장 형식 변경은 없습니다.

- 실제 렌더러 `sprite_layout`, `bond` 두 회귀 검사 통과. 종별 크기·동작 단위 고정 기준·화면 경계·확대 상한을 검사했습니다.
- 일반/이로치 2,316개 그림 경로, 112,549프레임, 74,188개 동작/화면 조합의 기하 검사 통과. 기존 누락 리소스는 변경하지 않았습니다.
- 승인된 비교 화면의 1,158개 예시와 새 크기가 모두 일치합니다. 리자몽 116×116, 잠만보 120×124, 피츄 74×80, 피카츄 61×92입니다.
- Android 3046, Wear OS 3047, ESP32 및 에뮬레이터 빌드 완료. 공개 APK 서명·리소스·ABI, ESP 파일 해시, 설치 도우미 동봉 파일은 `build-results.json`으로 확인합니다.
- 워치 Windows 설치 도우미 30개 검사 통과. 플레이 가이드 29쪽과 설치 도우미 가이드 7쪽을 렌더링하고 전체 페이지를 시각 확인했습니다.
- 게시 전 최종 커밋의 GitHub Actions 전체 64개 런타임 검사 및 나머지 배포 검사가 성공해야 합니다. 실제 결과는 [검증 작업](https://github.com/Loaram/TamaPoke_ko/actions/workflows/verify.yml)에서 확인합니다.

첨부 화면은 테스트 저장으로 촬영한 실제 에뮬레이터 화면입니다. 이번 버전의 실제 폰·워치·ESP 설치 및 성능은 직접 기기에서 검증하지 않았습니다.
