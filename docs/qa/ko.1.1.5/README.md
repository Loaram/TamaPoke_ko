# ko.1.1.5 검사·빌드 기록

## 변경 사항

- 도감 1~1025의 최신 본편 자연 습득표를 반영했습니다. 실제 기술 695개(빈 기술 포함 696항목), 원본 자연 습득 기술 689개, 원본 습득 14,542행, 게임 내 포켓몬별 습득 목록 26,422행입니다.
- 진화 대상 242종에 진화 즉시 습득 253행을 연결했습니다. 마스카나의 `트릭플라워`를 포함해 가라르·팔데아 스타팅 최종 진화 기술도 진화 순간에 제안됩니다.
- 기술 번호를 16비트로 확장하고 저장 형식을 버전 2, LAN 대전·세이브 전송 규격을 프로토콜 4로 올렸습니다. ko.1.1.4의 1바이트 기술 기록과 이전 저장은 불러올 때 자동 변환합니다. LAN 대전과 세이브 전송은 양쪽 모두 ko.1.1.5여야 합니다.
- 박스를 6마리씩 10페이지, 총 60칸으로 확장하고 페이지 표시를 숫자로 바꿨습니다. 기존 18칸은 앞쪽에 그대로 보존됩니다.
- 수면 중 활력 회복을 분당 8로 조정했습니다.
- 방어 훈련 결과에 실제 상승량 `방어 +N`을 표시하고 활력 소모를 점수와 무관하게 12로 조정했습니다.

- 한글 글꼴 788글자, 이름 1,900개, UI 문구 184개, 포켓몬 1,025종, 기술 696항목 검사 통과
- 저장·구버전 변환·세이브 전송·LAN 대전·전투·진화·기술·박스·터치·훈련을 포함한 런타임 29개 묶음 통과
- 1,025종의 레벨 1·100 기본 기술, 253개 진화 기술, 255 초과 기술 번호의 저장 및 대전 전송 검사 통과
- 웹 설치기 9개 지역 팩, 펌웨어 배치 및 NVS 저장 영역 보존 검사 통과
- `ko.1.1.5-dex`, `ko.1.1.5-shiny` 비공개 에뮬레이터 빌드 및 전용 런타임 검사 통과. 두 실행 파일은 공개 배포에서 제외합니다.
