# ko.1.0.7 그림 없는 진화 계보의 알 출현 제한 검증

ko.1.0.7은 현재 배포 자료에 표시 이미지가 없는 포켓몬과, 그 포켓몬으로 이어지는 진화 계보의 앞 단계를 알 후보에서 제외합니다. 포켓몬 번호와 세이브 구조는 바꾸지 않습니다.

## 알에서 나오지 않는 포켓몬

- 그림이 없는 19종: 바오키, 앗차키, 유토브, 줄뮤마, 제브라이카, 던지미, 암팰리스, 프로토가, 늑골라, 뽀록나, 탱그릴, 쪼마리, 버프론, 화염레오, 크라파, 형사구스, 춤추새, 마셰이드, 하랑우탄
- 진화 계보 때문에 추가로 제외한 9종: 바오프, 앗차프, 콩둘기, 돌살이, 깜놀버슬, 레오꼬, 콕코구리, 영구스, 자마슈

## 확인 결과

- 총 28종이 일반 알 추첨과 지방 변경 시의 알 재추첨에서 제외됩니다.
- 8개 지방 선택과 일반·희귀·전설 희귀도에서 9,600회 추첨해 제외 대상이 한 번도 나오지 않았습니다.
- 일반 진화와 분기 진화를 모두 따라가며 그림 없는 결과에 도달하는 앞 단계가 남아 있지 않은지 검사했습니다.
- ko.1.0.6에서 이미 제외 대상이 대기 중인 알에 들어 있던 상황을 재현해, ko.1.0.7 최초 실행 때 안전한 후보로 교체되고 다음 재시작에도 유지되는 것을 확인했습니다.
- 이미 부화한 포켓몬, 도감 등록, 포켓몬 번호, 저장·통신 형식은 변경하지 않았습니다.
- 한국어·문자열·저장·업그레이드·통신·밸런스·기술·도감·분기 진화·스타터·릴리스 회귀 검사와 Windows 에뮬레이터 빌드를 통과했습니다.
- 비공개 도감 완성판과 전체 이로치판은 같은 버전으로 빌드하지만 GitHub 릴리스와 설치 페이지에는 포함하지 않습니다.
- 설치 펌웨어가 NVS와 FFat 세이브 영역을 침범하지 않는지 검사했습니다.
- ESP32-S3 펌웨어는 프로그램 공간 1,850,639바이트(58%), 전역 RAM 66,884바이트(20%)를 사용하며 앱 파일 크기는 1,850,784바이트입니다.
- 펌웨어 파일별 크기와 SHA-256은 [build-info.json](build-info.json)에 기록했습니다.

실기 화면·터치·전원·SD·소리·무선 대전은 아직 확인하지 않았습니다.
