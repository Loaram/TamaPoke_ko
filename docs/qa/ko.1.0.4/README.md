# ko.1.0.4 전체 기술 검증

## 수정 내용

- 꼬시레(#767)의 레벨 1 기술 **벌레의저항**을 추가했습니다.
- 기술표에 사용할 수 있는 초반 기술이 없는 포켓몬은 임시 **발버둥**으로 전투를 시작합니다.
- 이후 정상 레벨업 기술을 배우면 임시 발버둥이 자동으로 교체됩니다.
- ko.1.0.3에서 기술 없이 저장된 꼬시레는 업데이트 후 자동 복구됩니다.

## 검사 결과

- 809종 전부를 레벨 1과 레벨 100에서 생성: 빈 기술을 가진 포켓몬 0종.
- 809종의 모든 기술 슬롯 검사: 기술표 범위를 벗어난 번호 0건.
- 꼬시레 레벨 1: 벌레의저항 확인.
- 잉어킹 레벨 1: 임시 발버둥 확인. 레벨 15 몸통박치기 습득 시 자동 교체 확인.
- 기존 빈 꼬시레 저장 데이터 불러오기: 기술 자동 복구 확인.
- 한국어 문자열·이름·글꼴 검사 및 전체 에뮬레이터 회귀 검사 통과.
- 809종 이름·타입·6개 기본 능력치·진화 연결·동일 타입 공격 기술 검사 통과.
- 모든 종의 지방 소속, 진화 전용 개체의 도달 가능성, 지역별 알 선택과 스프라이트 제외 규칙 검사 통과.
- 7개 지방 체육관 명단의 도감 번호·레벨·팀 크기·난이도 상승 검사와 전투 엔진 검사 통과.
- ESP32-S3 펌웨어 빌드: 앱 1,850,224바이트, 프로그램 영역 58%, 전역 RAM 66,884바이트.
