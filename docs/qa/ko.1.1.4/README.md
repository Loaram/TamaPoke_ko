# ko.1.1.4 1일 작별 검증

`ko.1.1.4`는 20분당 1레벨 성장 속도에 맞춰 최종 진화 포켓몬의 작별 제안 시점을 2일에서 1일로 줄인 정식 버전입니다.

## 동작

- 23시간 59분까지는 작별이 열리지 않습니다.
- 24시간(1,440분, 레벨 73)부터 최종 진화 포켓몬에게 작별 버튼이 열립니다.
- 최종 진화 전, 수면 중, 영구 동료 상태에서는 기존처럼 작별을 제안하지 않습니다.
- 작별을 거절하면 하루 뒤 다시 제안하는 규칙은 유지합니다.
- 조기 돌봄 종료는 작별 보너스를 주지 않고 다음 포켓몬의 진화를 늦추지 않는 기존 규칙을 유지합니다.

## 자동 검사

- 1일 직전과 정확한 1일 경계, 레벨 73 계산 통과.
- 조기 돌봄 종료, 정상 작별, 다음 알 보너스와 진화 패널티 회귀 검사 통과.
- 1일 레벨 73, 1일 9시간 레벨 100, 장기 오프라인 레벨 상한 검사 통과.
- 전체 런타임 21개 묶음, 한국어 데이터, 설치 페이지와 설치 파일 검사를 통과했습니다.
- ESP32-S3 스케치는 1,902,335바이트(60%), 전역 RAM 74,036바이트(22%), 배포 `app.bin`은 1,902,480바이트이며 NVS·FFat 영역을 덮어쓰지 않습니다.
- Android APK는 `ko.1.1.4-android.1`(versionCode 1116), 301,290,726바이트, ARM64/x86_64이며 APK v2/v3 서명을 확인했습니다.
- Galaxy Watch4~9 APK는 `ko.1.1.4-wear.1`(versionCode 1117), 301,016,299바이트, armeabi-v7a/arm64-v8a이며 APK v3 서명을 확인했습니다.
- 비공개 `ko.1.1.4-dex`, `ko.1.1.4-shiny` 에뮬레이터를 각각 빌드·실행했으며 GitHub에는 공개하지 않습니다.
- `ko.1.1.3` 릴리즈의 Galaxy Watch4~9 설치 가이드를 내용 변경 없이 `ko.1.1.4` 이름으로 복사했습니다. 11쪽 A4 PDF, 186,624바이트이며 전체 페이지 렌더링과 SHA-256 `36fc2e29fcd446b414a147c021f643c02f1716866ecf5fae445b2803a5dd44ce`를 확인했습니다.
