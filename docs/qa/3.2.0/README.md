# 3.2.0 검증 기록

## 변경 범위

도감 기반 알 보너스와 트레이너 화면, 안내 문서만 변경했습니다. `egg_rewards.h`의 정수 보간으로 기존 단독 최대 이로치 10%·전설 14%, 두 목표 합산 최대 15%·21%를 보존합니다. 목표는 유효 연속 돌봄 10일과 실제 수집 가능 도감 50%(현재 982종 중 491종)입니다. 전설 25종 해금/도망/지역 후보 제약은 유지합니다.

## 자동 검증

- 런타임 50개: `runtime.log`. 새 `dex_rewards`는 모든 등록 수 0~982 × 연속 일수 0~12에 독립적인 네 모서리 보간 기준식을 대조합니다. 정확한 단독/합산 확률, 단조 증가, 목표 이전 최대치 방지, 홀수 분모·0 분모·큰 입력, NO_ART 제외, 중복/이로치 중복 제외, 연속 단절, 전설 제한, 기존 알 유지, 저장 v7 왕복을 포함합니다.
- 기존 일일 보너스 검사와 UI 검사를 도감 기여에 맞게 확장했습니다. 3.1.1 파일 저장·재시작·연속 기록 회귀 검사도 유지합니다.
- SD 저장 실패/복구 검사 10개: `sd-store.log`.
- 한국어/8·9세대/폼/설치 페이지 검사: `static-checks.log`. 기존 기술 ID 695개, 폼 176개·그림 344개·기술 717종을 보존합니다.
- Android ARM64/x86_64(3022), Wear ARM32/ARM64(3023), ESP32-S3, 일반 PC와 비공개 두 에뮬레이터 빌드 로그를 동봉합니다.
- 공개 자산 6개의 크기·SHA-256, APK 내 모든 그림 팩/폼 팩 일치, ABI, ESP 앱 일치, PDF 24쪽 및 원본 워치 설치 PDF 불변을 `build-results.json`에 기록합니다.

## 화면·가이드 검수

실제 에뮬레이터 프레임버퍼인 `egg-bonus-dex-only.png`, `egg-bonus-max.png`, `egg-bonus-max-en.png`를 확인했습니다. 도감 수·달성률과 다음 알 확률을 보여 줍니다. 초기 배치에서 페이지 점과 겹치던 안내를 위로 옮기고 배지 간격을 조정한 뒤 최종 빌드와 전체 검사를 다시 실행했습니다.

플레이 PDF 24쪽을 모두 렌더링하여 `guide-contact-1.png`~`guide-contact-4.png`로 확인하고 변경된 21쪽은 원본 크기로도 검수했습니다. 목표 491종, 단독/합산 표, 전설 25종 해금과 기존 알 유지 규칙이 들어 있습니다. 워치 설치 PDF는 원본 바이트를 그대로 동봉합니다.

## 저장 호환성과 한계

저장 v7/최대 32,768바이트, TFR3/22,116바이트, 무선 프로토콜 5와 ESP NVS/SD 구성은 바뀌지 않습니다. 새 필드를 추가하지 않고 기존 도감과 연속 기록으로 계산합니다. 3.1.1의 파일 복원 수정도 포함하지만 이미 덮어쓴 연속 기록을 최고 기록에서 추측 복구하지 않습니다.

실제 Android·Galaxy Watch·ESP 설치, 물리적 SD 전원 차단, 기기 간 무선 시험은 실시하지 않았습니다. PC 검사·컴파일 성공을 실기 검증으로 표현하지 않습니다. 비공개 도감/이로치 해금 에뮬레이터는 공개 자산에 포함하지 않습니다.
