# ko.1.1.6 검사·빌드 기록

## 수정 사항

- 체육관 목록과 팀 선택 화면에서 고른 지역을 전투 시작 시 `btlRegion`에 고정합니다.
- 관장 이름, 첫 상대와 후속 팀, 승리 화면, 배지 지급이 모두 동일한 지역 명단을 사용합니다.
- 저장 형식과 무선 프로토콜은 ko.1.1.5와 같은 버전 2·프로토콜 4입니다.
