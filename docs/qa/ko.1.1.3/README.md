# ko.1.1.3 Android 기기 시각 동기화 검증

`ko.1.1.3`은 Android·Wear OS의 성장 시간과 설정 화면 시계를 휴대전화·워치의 날짜 및 시간 설정에 직접 맞춥니다.

## 수정한 문제

- 이전 앱은 단조 증가 실행시간으로 성장시키면서 별도의 앱 내부 RTC 오프셋으로 시계를 표시했습니다. 앱 중단·재개 또는 프로세스 재생성 뒤 두 기준이 달라질 수 있었습니다.
- 설정 화면의 시각은 화면을 열 때 한 번만 읽어 분이 바뀌어도 표시가 그대로였습니다.
- 기기 시각을 뒤로 바꾸면 부호 없는 시간 차가 매우 큰 양수로 해석될 여지가 있었습니다.

## 적용한 보호

- Android·Wear OS에서는 기기 Unix 시각을 성장과 표시의 단일 기준으로 사용합니다.
- 60초가 실제로 지난 경우에만 게임 1분을 적용하고 20분마다 1레벨이 오르는 기존 규칙을 유지합니다.
- 기기 시각이 뒤로 바뀌면 진행을 되감거나 대량 적용하지 않고 새 시각에 기준을 다시 잡습니다.
- ko.1.1.2 이하 저장은 ko.1.1.3 첫 실행 때 현재 포켓몬과 레벨을 유지하고 저장된 시각만 현재 기기 시각으로 바꿉니다.
- 앱이 중단·종료될 때 현재 진행 상태와 기기 시각을 함께 저장합니다.

## 자동 검사

- 전체 런타임 21개 묶음 통과.
- 기기 시각 59초에서 성장하지 않고 60초에서 정확히 1분 성장하는 경계 통과.
- 시각을 뒤로 조정해도 나이·레벨이 갑자기 증가하지 않고, 새 기준에서 60초 뒤 정상 진행하는 검사 통과.
- Android Full 네이티브 ARM64/x86_64 컴파일, ZIP 정렬, 네이티브 진입점과 APK v2/v3 서명 확인.
- Wear OS 네이티브 armeabi-v7a/arm64-v8a 컴파일, ZIP 정렬과 APK v3 서명 확인.
- ESP32-S3 펌웨어, 한국어 데이터, 9개 설치 팩, NVS·FFat 비침범과 설치 페이지 회귀 검사 통과.
