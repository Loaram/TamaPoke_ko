# 3.8.0 하루 두 번 알 수령 검수

메뉴 수령은 하루 2회이며 좋은 작별 조건 없이 현재 개체를 파티→박스로 보관합니다. 사용자 선택에 따라 도망 후 자동 알과 최초 알은 별개로 유지합니다. 세이브 v7·개체 72바이트는 유지하고 eggQuota·eggClaim 키를 추가합니다.

- daily_egg: 1회/2회 수령·초과 거부·알 보유·파티/박스 가득 참·재시작·교체·자정·시계 역행·날짜 없음·세이브 전송·구버전 횟수 변환 검사.
- 저장 키 오류와 두 수령의 134개 원자 쓰기 중단 지점을 재생하여 개체 소실·중복·재추첨·중복 차감 여부를 확인합니다.
- balance, forms, daily_rewards, ending_recovery, companion_growth, release, daily_rewards_ui 로컬 검사 통과. 이전 저장의 진행 중인 작별만 복구하는 호환 경로도 유지합니다.
- 로컬 retire 실행은 Windows WinError4551로 차단됐으므로 통과로 주장하지 않습니다. 최종 커밋의 전체 65개 런타임·Java 통신·SD 저장·ESP 서버 빌드 통과를 공개 필수 조건으로 삼습니다.
- 새 알 메뉴·확인·횟수 소진 화면은 실제 에뮬레이터 렌더러에서 캡처합니다. 플레이 가이드 29쪽·설치 도우미 가이드 7쪽 전체를 렌더링하여 확인합니다.
- 서명·해시·ABI·그림 팩·ESP·설치 ZIP·PDF의 정확한 배포 파일은 build-results.json에 기록합니다.

실제 폰·워치·ESP 설치, 실제 기기 간 무선 및 물리적 SD 전원 차단은 이번 검수에 포함되지 않습니다. 앱을 삭제하지 말고 업데이트 전에 세이브를 백업하세요.
