# 3.5.1 통신 메뉴 문구 패치 검수

게임 변경은 `TamaPoke.ino`의 버전과 메뉴 표시 문자열 선택뿐입니다. 기존 `S_LAN`은 대전 항목에 유지하고 체육관 두 입구 및 연결 메뉴 제목에만 `통신 메뉴`를 표시합니다. 저장·패킷·밸런스·버튼 위치·행동 처리는 변경하지 않습니다.

## 로컬 자동 검증

- 한국어 표·이름·글꼴 검사, 8/9세대 데이터·폼 자산 검사, 웹 설치 오류/복구 검사 통과.
- 집중 런타임 7개 통과: `korean`, `i18n`, `label`, `lan`, `trade_ui`, `savetransfer`, `upgrade`. `lan`에 한국어 통신 메뉴, 실제 대전 이름 유지, 영어 기존 이름 유지 3가지 검사를 추가했습니다.
- SD 저장 실패·복구 10개 통과. 실제 SD 카드에 기록한 시험이 아닙니다.
- Android 3030 / Wear 3031. 기존 서명·패키지를 유지하며 APK 서명·정렬·버전·ABI·그림 팩·통신 메뉴 문자열을 검사합니다.
- Windows 도우미 30개 검사 및 완성된 번들의 런타임 파일 검사 통과. 정식 Wear APK와 같은 파일을 동봉합니다.
- 일반 에뮬레이터, 도감 해금·이로치 도감 해금 점검 에뮬레이터를 빌드했습니다. 해금 에뮬레이터는 로컬에만 보관합니다.
- `gympick.png`, `gymsj.png`, `lan.png`는 실제 게임 렌더러가 만든 화면으로, 버튼 안 글자와 기존 대전 선택지를 확인했습니다.
- 플레이 PDF 27쪽과 설치 도우미 PDF 7쪽을 렌더링해 확인했습니다. 기존 수동 워치 설치 PDF는 원본과 같은 검사값을 유지합니다.

배포 파일의 크기·SHA-256과 검사 결과는 `build-results.json`에 기록합니다. ESP32 분할 이미지의 NVS 보존 배치도 검사합니다. 전체 55개 런타임은 별도의 GitHub 검증 워크플로에서 수행하며 로컬 집중 검사와 구분합니다.

## 실물 검증 한계

실제 Android·Galaxy Watch·ESP32에 설치하거나 기기 사이 무선 통신을 새로 시험하지 않았습니다. 워치 설치 도우미는 계속 시험판입니다. Windows 보안 설정은 변경하지 않았으며, 로컬 컴파일러 접근은 일반 사용자 실행 권한으로 검증했습니다.
