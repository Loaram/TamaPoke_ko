# 3.7.1 워치 통신 버그 패치 검증

사용자는 정식 3.7.0 폰끼리 통신 성공, 폰↔워치 대전·세이브 이전 실패를 보고했다. 블루투스를 끄고 다른 폰의 핫스팟을 사용해도 실패했다. 수정 테스트 APK와 설치 도우미를 제공한 뒤 2026-09-08 “이제 잘된다 업로드 해줘”라는 확인을 받았다.

이는 사용자 기기 조합의 해결 확인이다. 개발자가 직접 패킷을 수집한 결과나 모든 모델/ESP 실기 검증으로 확대하지 않는다. 정식판은 확인된 테스트판의 통신 코드를 유지하고 FW_VERSION·APK 버전 코드만 올렸다.

## 변경 범위

Wi-Fi Network 확보·binding, IPv4 LinkProperties 기반 검색, MulticastLock과 종료 시 해제, 재시도 소켓 재생성, IP/TX/RX/E 진단, 검색 실패 메시지 구분. 저장 및 밸런스 소스는 변경하지 않았다.

테스트 설계는 [통신 수정 후보 검증](../3.7.1-lan-test/README.md)을 참고한다.

## 배포 검사

tools/record_release_371.py가 빌드 로그·62개 회귀 검사·Java 20개·SD 장애 10개·설치 도우미 30개 검사와 공개 자산 9개를 대조한다.

- Android: versionCode 3042, ARM64/x86_64. Wear: versionCode 3043, ARM32/ARM64.
- 기존 정식 서명과 앱 ID 유지. 저장 v7 / 개체 72바이트 / 세이브 프로토콜 3 / 대전 5 / 교환 1.
- 플레이 PDF 29쪽·도우미 PDF 7쪽 렌더링 확인. 기존 수동 설치 PDF는 원본 그대로 첨부.
- 네이티브 통신 29개 확인(300칸 세이브 양방향·손실 포함)이 전체 런타임에 포함된다. 실제 Activity 콜백 20개는 가상 Android OS에서 별도 실행한다.

최종 SHA-256과 빌드/검사 결과는 같은 폴더의 build-results.json 및 로그에 기록한다.
