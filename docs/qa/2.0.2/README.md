# 2.0.2 검사·빌드 기록

기록일: 2026-09-06

## 변경과 버전 기준

- 도감 진행도를 `도감 1/1025(982)`로 표시합니다. 기존 등록 종수와 전국 번호는 유지하며, 전체 빌드에서 수집 가능한 종수를 괄호로 추가했습니다. 지역 선택·지역별 도감, 메뉴, 알 화면과 트레이너 카드에 같은 기준을 적용합니다.
- `NO_ART`에서 자동 집계하며 알 후보에서 제외되어도 탐색으로 잡을 수 있는 종은 포함합니다. 설치된 지역 팩 유무 때문에 전체 목표 숫자가 바뀌지는 않습니다.
- 사용자 지정 `a.b.c` 규칙을 AGENTS와 README에 기록했습니다. 기능 추가·대규모 변경은 a, 기능 수정·밸런스 패치는 b, 텍스트·간단한 패치는 c입니다. 이번 표시는 간단한 패치이므로 2.0.2입니다.
- 포켓몬 번호·등록 기록·저장 형식·무선 프로토콜 4·밸런스는 유지합니다. 취소된 폼체인지 작업은 포함하지 않습니다.

## 검증

- 한국어 193개 UI, 1,025종·695개 기술, 789글자 글꼴 검사 통과.
- 최종 2.0.2 스케치로 런타임 33개 묶음 통과. Windows 실행 정책으로 제한된 테스트는 승인된 실행 환경의 격리된 테스트 저장 폴더에서 다시 실행했습니다.
- 모든 지역·희귀도 탐색 후보의 합집합은 982종이며 표시 집계와 정확히 일치합니다. 지역별 합계, 없는 팩, 잘못된 번호 범위도 검사했습니다.
- 7개 언어의 최대 자릿수 폭과 원형 화면 제목·지역 행·메뉴 버튼 간격을 검사했습니다. 실제 에뮬레이터 메뉴·지역 선택·도감 캡처를 확인했습니다.
- ESP32 스케치 2,142,779바이트(68%), 전역 RAM 83,988바이트(25%), 앱 2,142,928바이트. NVS/FFat 비침범 검사 통과.
- Android versionCode 2004, 303,457,510바이트, ARM64/x86_64. Wear OS versionCode 2005, 303,088,875바이트, ARM32/ARM64.
- 두 APK의 ZIP 무결성·페이지 정렬·서명을 검사했습니다. 서명 인증서 SHA-256은 `17aaf3ebfaa9b51599e2b0d0970f99651bd8be6700da981b7f240677535b7f47`이며 기존 2.0.1 APK와 같습니다.
- 일반·비공개 -dex/-shiny 에뮬레이터를 빌드하고 각각 화면을 렌더링했습니다. 개인 세이브는 사용하지 않았고 비공개 완성판은 릴리스에 포함하지 않습니다.
- 18쪽 플레이 가이드에 도감 표기와 수집 기준을 추가하고 도감 이미지를 갱신했습니다. 모든 페이지를 렌더링하고 변경된 6·10쪽을 확대 확인했습니다. 기존 워치 설치 PDF는 내용 변경 없이 첨부합니다.
- 공개 자산은 APK 2개, ESP32 설치 ZIP, PDF 2개와 SHA256SUMS.txt만 허용합니다. 업로드는 초안에 먼저 수행하고 서버 측 SHA-256 확인 후 공개합니다.

## 실기 한계

실제 Android·Galaxy Watch4~9·ESP32 설치, 화면·터치와 기기간 대전/세이브 전송은 이번 작업에서 직접 확인하지 않았습니다. 자동 검사와 빌드 통과를 실기 검증으로 해석하지 않습니다.
