# TamaPoke 2.0.2

도감에서 실제 수집 가능한 포켓몬 수를 함께 보여주는 표시 개선 패치입니다.

- 전국 진행도: `도감 1/1025(982)` = 등록 1종 / 전체 도감 번호 1025종 / 현재 수집 가능 982종.
- 지역 선택 목록과 지역별 도감 제목에도 각 지역의 수집 가능 종수를 표시합니다.
- 괄호 안 숫자는 전체 그림 팩 기준으로 자동 계산합니다. 알에서는 나오지 않아도 탐색으로 잡을 수 있는 종을 포함하며 그림 미지원 43종을 제외합니다.
- 기존 포켓몬 번호, 도감 등록 기록, 세이브·무선 프로토콜 4와 게임 밸런스는 변경하지 않습니다.
- 한국어 플레이 가이드 6쪽에 새 표시의 뜻과 수집 가능 기준을 추가했습니다. 기존 Galaxy Watch4~9 설치 가이드도 함께 첨부합니다.

## 다운로드와 업데이트

- Android 휴대전화: `Android-Full-debug.apk` (ARM64/x86_64, versionCode 2004).
- Galaxy Watch4~9: `WearOS-GalaxyWatch4-9-debug.apk` (ARM32/ARM64 통합, versionCode 2005).
- ESP32: `ESP32-Web-Installer.zip` 또는 [웹 설치 페이지](https://loaram.github.io/TamaPoke_ko/).
- 플레이 가이드·워치 설치 가이드 PDF와 `SHA256SUMS.txt`를 첨부합니다. 도감 완성·이로치 완성 테스트 에뮬레이터는 공개하지 않습니다.

앱은 기존 서명 키로 만들었습니다. 저장을 유지하려면 기존 앱을 삭제하지 말고 덮어쓰기 설치하세요. ESP32 업데이트에서는 **Erase device를 선택하지 마세요**. 통합 `tamapoke.bin`은 빈 기기용이며 기존 저장 유지 업데이트에는 사용하지 않습니다.

## 버전 번호 기준

앞으로 `a.b.c`에서 a는 기능 추가·대규모 변경, b는 기능 수정·밸런스 패치, c는 단순 텍스트·간단한 패치입니다. 상위 번호가 오르면 하위 번호는 0으로 초기화합니다. 이번 도감 표시는 간단한 표시 개선이므로 2.0.1 → 2.0.2로 올렸습니다.

에뮬레이터·자동 검사와 빌드를 검증했으며 실제 Android·워치·ESP32 설치 및 기기간 통신 재검증은 아직 실시하지 않았습니다.
