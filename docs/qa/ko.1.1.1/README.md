# ko.1.1.1 Android·Wear OS·실기 LAN 대전 검증

`ko.1.1.1`은 Android판에 빠져 있던 실제 LAN 통신을 추가하고 ESP32의 기존 ESP-NOW 대전과 Android용 UDP 대전을 함께 지원합니다.

## 동작 방식

- Android ↔ Android: 두 기기를 같은 Wi-Fi에 연결하고 양쪽에서 근거리 대전 팀을 선택합니다.
- ESP32 ↔ ESP32: 기존과 같이 채널 1의 ESP-NOW를 사용합니다.
- Android ↔ ESP32: 실기가 여는 `TamaPoke-XXXX` Wi-Fi에 Android를 연결한 뒤 양쪽에서 팀을 선택합니다. 암호는 `tamapoke`입니다.
- UDP 포트는 38631이며, 첫 유효 상대를 찾은 뒤 해당 IP·포트·송신자 번호만 허용합니다.

## 확인한 내용

- Android의 ARM64와 x86_64 네이티브 라이브러리가 소켓 생성·바인드·브로드캐스트 송신·비차단 수신 코드를 포함해 링크됐습니다.
- APK에 인터넷·네트워크·Wi-Fi 상태 권한과 9개 지역 스프라이트 팩이 포함됐습니다.
- Android 17의 로컬 네트워크 권한을 선언하고, 근거리 대전을 처음 시작할 때 시스템 권한 창을 요청하도록 했습니다.
- 공용 UDP 봉투의 왕복, 송신자 보존, 다른 트래픽, 잘못된 길이, 0 송신자 거부 테스트를 통과했습니다.
- 기존 Link 프로토콜의 팀 교환·호스트 결정·턴·재전송·버전 불일치·패킷 검증 회귀 테스트를 통과했습니다.
- ESP32-S3 빌드에서 기존 ESP-NOW와 SoftAP/UDP 하이브리드 통신이 함께 컴파일됐습니다.
- 프로그램 1,897,935바이트(60%), 전역 RAM 68,684바이트(20%), 배포 앱 파일 1,898,080바이트입니다.
- Android APK `ko.1.1.1-android.1`, versionCode 1103, 301,278,438바이트. SHA-256은 `0533290f8be228cbafa2d9ed6c206c89344ec87772313a5e1ce79407de76880d`입니다.
- APK v2/v3 서명, 16KB 페이지 정렬과 ARM64/x86_64 구성을 확인했습니다. 서명 인증서는 ko.1.1.0 APK와 동일합니다.
- Galaxy Watch4~9 통합 Wear OS APK는 `ko.1.1.1-wear.2`, versionCode 1105, 300,991,723바이트입니다. 워치 전용 기능 선언, 독립 실행 설정, `armeabi-v7a`·`arm64-v8a`, 9개 팩과 v3 서명을 확인했습니다. SHA-256은 `13dd705328e732c94347576a4fe3d3f318adcf63f35fd8ebde424d59ebf01e10`입니다.
- 동일한 466×466 원형 버퍼를 42mm 396×396과 46mm 450×450으로 비율 유지 축소한 미리보기에서 제목·상태·하단 버튼이 원형 안전 영역 안에 들어오는 것을 확인했습니다.

## 아직 확인하지 못한 내용

연결 가능한 Android 기기, Galaxy Watch4~9와 ESP32 실기가 동시에 없어 실제 앱↔앱, 앱↔실기 및 워치 화면·터치·LAN 전투 완료는 아직 확인하지 못했습니다. 이 항목은 실기 테스트 전까지 성공으로 기록하지 않습니다.
