# 3.1.0 박스 정렬 검증

합성 세이브와 에뮬레이터로 검사합니다. 사용자의 실제 저장은 변경하지 않습니다. 최종 빌드 해시·플랫폼·로그는 `build-results.json`과 동봉 로그를 확인하세요.

## 정렬 회귀 검사

- 300칸/50페이지 전체 정렬, 빈 박스·한 마리·빈칸이 흩어진 박스·가득 찬 박스.
- 공식 한국어 이름 가나다순: 별명과 화면 언어와 무관. 도감 번호 오름차순, 레벨 내림차순.
- 동률의 기존 순서, 255번 이후 칸, 전체 72바이트 개체 기록의 보존.
- 저장 후 재시작과 v7 전체 세이브 내보내기/가져오기 후 순서 보존.
- 파티와 현재 포켓몬, 작별 횟수 불변; 잘못된 기준·도감 번호 거부.
- 정렬 메뉴·확인·취소·스와이프의 모달 동작. 취소 시 페이지/교체 대기 유지, 성공 시 첫 페이지와 선택 초기화.
- 정렬 후 상세창·놓아주기 취소·가득 찬 파티 교체가 정확한 개체를 대상으로 동작.
- 저장 실패 시 오류 표시, 메모리의 모든 원래 기록 및 저장된 순서 유지, 읽기 전용 상태에서 재시도 거부.
- 기존 박스 직접 놓아주기/교체와 50페이지 이동 검사 포함.

전체 런타임은 47개 묶음입니다. 별도로 SD 저장의 10개 장애·복구 검사, 한국어/데이터/폼/웹 정적 검사와 웹 설치기 테스트를 수행합니다. Android·Wear·ESP·일반 에뮬레이터 및 비공개 전체 도감/이로치 에뮬레이터를 빌드합니다.

## 동료 성장·개체값 검사

- 이전 포획 기록의 활성 성장(19분/20분 경계), 일반 진화와 개체값 보존.
- 보관 중 정지, 남은 성장 분 복원, 저장 후 재시작.
- 실제 좋은 작별 기록을 300번째 칸에서 데려와 73→74 성장, 재작별/도망 보호와 레벨 100 상한.
- Android 콜드 시작·백그라운드 복귀 시 성장, 중복 적용과 시계 역행 방어.
- 공격/방어/속도/체력과 0·17·24·31 개체값 매핑, 폼 능력치와 개체값의 구분.

## 화면과 문서

`box-sort-menu.png`, `box-sort-confirm.png`, `box-sort-result.png`는 합성 데이터로 렌더링한 실제 게임 UI입니다. 플레이 가이드 24쪽 전체를 렌더링하고 정렬 페이지를 확대 검수합니다. 설치 가이드는 원본과 SHA-256이 같은 파일을 첨부합니다.

## 제한

실제 기기 설치, SD 물리 분리/전원 차단, Android↔Wear↔ESP 무선 통신은 이번에 직접 시험하지 않았습니다. 실기에서 장시간 사용과 메모리 압박 검증은 별도로 필요합니다. 세이브 구조나 통신 규격, 데이터와 성장 간격은 변경하지 않았습니다.
