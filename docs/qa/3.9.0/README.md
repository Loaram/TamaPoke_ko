# 3.9.0 검증 범위

새 인게임 초기화: 실제 설정/확인창 터치, 취소와 연속 입력, 대전·전송·교환·보관 중 차단, 300칸 박스와 도감·훈련·알 횟수 삭제, 설정 유지, 초기 알·활력80·알 수령2회로 새 게임 시작을 검사한다.

`reset_test.cpp`는 초기화 도중 67개의 원자 저장 변경 경계 스냅샷을 재생한다. 각 지점에서 다시 시작해 초기화를 완수하고 옛 SD 포인터가 사라지는지 검사한다. 의도 저장 실패, 개별 삭제 실패, 3단계 파일 체크포인트 실패, 실제 부팅 복구/재시도, Android 자동저장·중단·복귀, 실제 NVS 파일 쓰기/재읽기도 포함한다. 상대의 미수신 교환 완료를 복구할 내부 기록은 삭제하지 않는다.

최종 보완: 최초 ESP 설치의 없는 namespace를 초기화 동의로 해석하지 않는다. Android 오류 화면에서 백그라운드→복귀해도 재시도 UI가 반응한다. NativeActivity 종료 후 같은 프로세스에서 다시 생성되어 C++ 전역 개체가 남는 경우도 실제 setup 재진입으로 검사한다. 성공한 초기화 후 기존 Pet/Party를 복사하지 않고 재생성하며 초기화 잠금·설정 화면·이전 지방 선택을 해제한다. 마지막 `reset-warm.log`의 전용 검사와 67개 중단 지점은 모두 통과했다.

초기 로컬 초기화·Android lifecycle·세이브·교환 전용 검사는 통과했다. 최종 보완 후 초기화(복귀 UI 반응 포함)·세이브·교환을 다시 확인하며 별도 Android lifecycle 실행파일과 전체 로컬 검사 일부는 Windows WinError4551 정책으로 차단되어 완주하지 못했다. 이를 성공으로 계산하지 않으며, 최종 커밋의 GitHub Verify Korean edition 전체 66종·Java 통신·SD·ESP 빌드 성공을 공개 조건으로 한다. 보안 설정은 변경하지 않는다.

공개 산출물·APK 서명/ABI/그림·버전·ESP 해시·PDF 30/7쪽·워치 도우미 포함 APK는 `build-results.json`과 빌드 로그에서 검증한다. 플레이 가이드는 30쪽 전부 렌더링하고 초기화 안내를 별도 확인한다. 원본 워치 수동 설치 PDF는 그대로 첨부한다.

실제 ESP·폰·워치 초기화나 물리 전원 차단은 이번에 수행하지 않았다. 사용자의 기기·세이브·SD는 변경하지 않았다. 초기화는 게임 재시작 기능이며 SD 잔존 파일/외부 백업까지 복구 불가능하게 지우는 보안 삭제 기능이 아니다.
