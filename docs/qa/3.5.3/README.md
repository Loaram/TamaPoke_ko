# 3.5.3 버그 패치 검증

2026-09-07. 3.5.2 후속 시뮬레이션의 다섯 수정사항을 정식 패치로 묶는다. [원인과 수정 후 시뮬레이션 보고서](../3.5.2-followup/README.md), [릴리스 안내](../../RELEASE-3.5.3.ko.md).

후속 수정 코드에서 전체 런타임 58개, 저장 중단 1,056건(각 2회 재시작), 교체·훈련·재시작 1,200회, 통신 장애 조합 90건, SD 장애 검사 10개를 통과했다. 추가된 `recovery_clock`은 날짜 변경·복구 중 시간 정지·재시도 후 시간 기준을, `modal_safety`는 확인창 취소·키보드·저장 불가 탐색을 검사한다.

3.5.3 번호를 적용한 뒤 PC·Android·Wear·ESP와 로컬 점검용 두 에뮬레이터를 재빌드하고 전체 58개 런타임 검사를 다시 실행해 모두 통과했다. SD 장애 10개와 Windows 도우미 검사 30개도 통과했다. 공개 자산 검사는 `tools/record_release_353.py`로 실제 로그·서명·ABI·그림 팩·가이드 쪽수·워치 도우미 동봉 APK·SHA-256을 대조해 9개 모두 통과했다. 시뮬레이션 코드와 버전 표기를 제외한 바이트 동일성도 확인했다. 통과 기록과 배포 파일 해시는 `build-results.json`을 기준으로 한다.

저장 v7 / 개체 72바이트 / 배틀 5 / 거래 1, 기존 식별 번호와 밸런스는 변경하지 않는다. 실제 휴대전화·워치 설치, 실물 무선 및 SD 전원 차단은 미검증이다. 시뮬레이션 통과는 모든 기기의 무결함이나 이미 사라진 저장값 복원을 뜻하지 않는다.
