# 3.0.0 전체 시스템 검수

2026-09-06. 이전 베타 기능을 정식 버전으로 통합했습니다. 검수 중 수정 내용은 [릴리스 설명](../../RELEASE-3.0.0.ko.md)을 참고하세요.

## 확인한 범위

- **43개 런타임 검사 모음 통과**: 한국어, 저장/이전, 무선 모의 전송, 전투/AI/체육관, 성장/진화/기술, 탐색/포획, Android 시간 및 재개, 폼/폼 기술, 자유 교체, 연속 돌봄/작별 제한, 300칸/페이지 이동, 작별 재시작 복구.
- **10개 ESP SD 저장 실패 모의 검사 통과**: SD 없음, 부분 쓰기, 선택 표식 쓰기 실패, 재시도, 잘못된 카드/손상 데이터, 초기화 후 과거 기록 부활 방지.
- 한국어 802글자·194문자열·1968이름 매핑과 게임 기술 717종 검증. 이전 695종 기술 번호/데이터가 그대로인 것을 기존 정식 소스와 직접 비교했습니다.
- 폼 176개·애니메이션 파일 344개, 데이터/타입/능력치/출처 해시 확인. 별도 습득표 69개. 제외 폼의 기존 저장은 기본 모습으로 안전하게 표시합니다.
- 웹 설치 버전 확인, 9개 지방+폼 팩 파싱, 잘못된 파일 경로/잘린 데이터/전송 실패 처리 검증. 설치 manifest가 기존 NVS/FFat 영역을 침범하지 않는지 확인했습니다.

## 빌드와 공개 파일

| 구분 | 결과 |
|---|---|
| 일반 PC 에뮬레이터 | 빌드 및 실제 그림 파서/UI 검사 통과 |
| 비공개 `-dex`, `-shiny` | 각각 빌드, 공개 자산 제외 |
| Android | 3012, arm64-v8a/x86_64, 서명·16KB 정렬·ZIP/그림 팩 검증 |
| Wear OS | 3013, armeabi-v7a/arm64-v8a, 서명·16KB 정렬·ZIP/그림 팩 검증 |
| ESP32-S3 | 앱 이미지 2,237,232바이트, 전역 RAM 199,716바이트(60%) |
| 가이드 | 플레이 22쪽 전체 렌더/시각 확인, 워치 설치 PDF는 원본과 SHA-256 일치 |

두 APK·ESP 설치 ZIP·두 PDF·SHA256SUMS 총 6개 공개 자산을 검증했습니다. 공개 파일 및 비공개 테스트 실행 파일의 해시는 `build-results.json`에 있으며 테스트 실행 파일 자체는 업로드하지 않습니다.

## 발견하여 수정한 문제

1. 작별 완료 뒤 보관 전 종료 시 개체를 잃는 문제: 연출/대기 개체를 저장하고 다음 시작에 이어서 처리합니다. 보관 후 확인 기록 전 종료도 정확한 동일 개체 검사로 중복을 방지합니다.
2. 세이브 적용 시 저장 실패를 성공으로 처리하는 문제: 쓰고 나서 값을 검증하고 실패하면 기존 저장으로 복구를 시도합니다. 중복 키/잘못된 타입도 거부합니다.
3. 손상된 현재 개체 도감 번호에 따른 범위 밖 접근: 유효 범위를 검사하고 안전한 알 상태로 복구합니다.
4. 없는 폼 그림의 대체 표시가 갱신 후 사라지는 문제: 캐시 재사용 화면에서도 표시를 유지합니다.
5. 기존 데이터 검사 도구의 695개 기술/7개 체육관 고정 조건을 현재 717개/9개로 갱신하고 새 데이터도 검사하도록 확장했습니다. 폼 팩 전송 검사와 SD 오류 검사를 CI에 포함했습니다.

## 검증하지 않은 것

실제 휴대전화·워치4~9 전 모델·ESP 기기에는 설치하지 않았습니다. 실물 SD 전원 차단, 기기간 실제 무선 대전/세이브 전송, 센서/터치/배터리 표시와 장시간 실제 플레이는 별도 하드웨어 검증이 필요합니다. 모의 저장 실패 복구는 임의 시점 전원 차단의 완전한 안전성을 보장하지 않습니다. 업데이트·세이브 적용 전 백업과 원래 SD 보관이 필요합니다.
