# 3.7.0 공용 활력 검증

실제 게임 C++ 코드와 에뮬레이터 화면 경로를 사용하는 자동 검사다. 실제 휴대전화·워치·ESP 기기 설치나 무선 교환 시험을 대신하지 않는다.

## 수정 범위

- 데려오기 시 보관 개체의 활력/기본 80을 불러오던 경로를 제거했다.
- 교체 저널에 공용 활력을 기록하여 저장 중단 후 같은 값으로 복구한다.
- 새 알 생성은 활력을 유지하고 새 게임/초기화에서만 80으로 만든다.
- 정식 탐색 비용 22, 수면 회복 8/분, 세이브 v7·개체 72바이트를 유지한다.

## 시뮬레이션

- 보관 활력 0~100 × 파티/박스 = 202가지. 다른 돌봄·유대 보존, 교체 후 소모, 역교체, 재시작을 검사한다.
- 실제 탐색 시작/포획 처리에서 승리·포획 성공을 강제한 반복. 파티·박스 각각 포획 → 데려오기 → 재시작을 반복해도 100에서 4회 후 12에 멈춘다.
- 비용과 정확히 같은 활력 22에서 0이 되고 추가 탐색이 차단된다. 레거시·전송 개체 형태의 저장 기록을 데려와도 충전되지 않는다.
- 새 알·재시작·부화 후에도 유지하고 수면 1분으로 8 회복, 저장 재실행과 전체 v7 세이브 왕복을 검사한다.
- 파티/박스 × dexn/ene/age/ivat/liveCare 저장 실패 10건. 오래된 활력 키가 남아도 복구 값은 교체 당시 12이며 재부팅을 반복해도 변하지 않는다. 저널 기록 자체 실패도 검사한다.
- 전체 61개 런타임 회귀, 포획식 247,808 조합·500만 모의 포획, SD 장애 10건, Windows 워치 도우미 30검사.

## 빌드·문서

Android ARM64/x86_64, Wear OS ARM32/ARM64, ESP32-S3와 기본 에뮬레이터를 빌드한다. 정식 APK 서명·앱 ID·버전코드, 그림 팩, ESP 설치 주소, ZIP CRC와 SHA-256을 검증한다.

플레이 가이드 29쪽과 설치 도우미 가이드 7쪽을 렌더링하여 확인했다. 탐색 화면은 실제 3.7.0의 소모 22 표시로 교체했다. 기존 Galaxy Watch4-9 수동 설치 PDF는 원본 그대로 동봉한다.

최종 기계 검증 결과와 원본 로그는 이 폴더의 build-results.json, runtime.log, sd-store.log 및 빌드별 log 파일에 기록한다. Windows 보안 설정은 변경하지 않았다.
