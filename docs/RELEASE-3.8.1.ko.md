# 3.8.1 - ESP 연결 및 스프라이트 설치 버그 패치

기존 기능의 오류 수정이므로 패치 번호를 올렸습니다. 게임 규칙·확률·성장·하루 알 수령 횟수는 바뀌지 않습니다.

- **ESP ↔ 스마트폰 Wi-Fi 세이브 전송:** 상주하던 32KB 임시 버퍼를 필요할 때만 PSRAM에 할당하여 내부 메모리를 확보합니다. 기기 주소는 초기화된 드라이버에서 확인해 방 이름을 만듭니다.
- **세이브 적용 보호:** 적용 전 백업 공간 확보·백업 생성에 실패하면 받은 세이브를 적용하지 않습니다. 임시 공간은 작업 후 해제합니다.
- **USB 스프라이트 설치:** 실제 수신·쓰기 길이를 검사하고, 파일을 다시 읽어 크기와 CRC32를 확인한 뒤에만 완료를 알립니다. 오류 시 파일명·진행 바이트·실패 단계를 표시하고 중단합니다.
- **설치 오류 안내:** 이전 펌웨어의 단순 ERR와 상세 SD 오류를 구분합니다. SD 포맷이나 세이브 삭제부터 하지 말고 오류 기록과 케이블·카드를 확인하세요. 미완성 그림 파일은 해당 팩을 다시 설치해야 합니다.

ESP 테스트판에서 사용자가 스마트폰 Wi-Fi 연결, 세이브 전송과 적용 성공을 확인했습니다. 두 수정을 함께 적용했으므로 단일 원인을 확정하지 않습니다. 모든 기기 조합의 근거리 배틀이나 USB 그림 팩 전체 재설치 성공까지 확인한 것은 아닙니다.

## 업데이트

앱은 기존 앱을 삭제하지 말고 덮어 설치하세요. ESP 설치창의 **Erase device는 선택하지 마세요.** 기존 SD를 유지하고 업데이트 전 세이브를 백업하세요. 업데이트 후 ESP의 통신 화면에 표시되는 현재 `TamaPoke-XXXX` 이름으로 연결합니다. 이름이 이전과 달라질 수 있으며 암호는 `tamapoke`입니다. 인터넷 없음 안내에서는 연결 유지를 선택하세요.

저장 v7, 개체 72바이트, 통신 규격과 기존 세이브 호환을 유지합니다. Android 3050 / Wear 3051. 폰·워치 APK, ESP 설치 ZIP, 29쪽 플레이 가이드, 원본 Galaxy Watch 설치 가이드, Windows 워치 설치 도우미와 설명서를 함께 제공합니다.
