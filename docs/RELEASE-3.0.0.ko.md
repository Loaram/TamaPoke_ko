# TamaPoke 3.0.0

폼체인지·체육관·보관 시스템을 확장한 정식 버전입니다. 기능 추가와 대규모 변경이므로 사용자 버전 규칙에 따라 주 버전을 3으로 올렸습니다.

## 새 플레이 기능

- **지속형 폼체인지 176개**: 지방의 모습·메가진화·원시회귀·합체·오거폰·특수 타입 변화·지원하는 거다이맥스/무한다이맥스. 일반 60레벨, 메가 70레벨, 강력한 폼 80레벨. 애니메이션 없는 폼은 제외하며 타입과 기본 능력치도 반영합니다.
- **폼별 기술 목록 69개**와 추가 기술 22종(총 717종). 새 기술을 배울 때 사용자가 교체할 칸을 직접 선택합니다.
- **가라르·팔데아 체육관**: 총 9개 지방, 가라르는 소드/실드 코스. 원작의 첫 도전 팀·레벨과 공식 이미지를 참고하며 전투는 기존 단일 전투 규칙입니다.
- **자유 교체**: 알이 아닐 때도 파티/박스에서 현재 포켓몬과 맞교환합니다. 키우던 개체의 성장은 보관 중 정지하고 다시 데려오면 이어집니다. 포획·좋은 작별 동료는 성장 정지를 유지합니다.
- **박스 300칸 / 50페이지**: 이전·다음 버튼, 페이지 번호를 누르는 빠른 이동, 기존 스와이프를 지원합니다. 전투 후보는 현재 개체 1마리+보관 파티 5마리입니다.
- **연속 돌봄 알 보너스**: 1일차 이로치 1/48·전설 등급 3%에서 10일차 이로치 10%·전설 등급 14%까지 증가합니다. 전설은 도감 25종 등록 조건이 있으며 후보 없는 지역에서는 하위 등급으로 대체됩니다. 탐색 확률은 변하지 않습니다.
- **자발적 작별 하루 3회**: 좋은/일반 작별과 현재 개체 보내기를 합산합니다. 보관 이동·맞교환은 차감하지 않습니다. 좋은 작별은 일반 최종진화+부화 후 누적 성장 1,440분(73레벨)이며 폼 해금과 무관합니다. 자격을 얻으면 사용자가 작별을 선택하고 파티 우선·빈자리가 없으면 박스로 보관합니다.

## 전체 검수 중 수정

- 작별 연출·보관 대기를 저장하여 재시작 후 복구합니다. 보관 직후 재시작해도 같은 개체를 중복 추가하지 않도록 확인합니다.
- 저장 공간 쓰기에 실패한 세이브 적용을 성공으로 처리하지 않고 기록을 재검사하며 기존 값을 복구하도록 했습니다.
- 손상된 현재 포켓몬 번호가 도감 범위를 벗어나 접근하지 않도록 방어했습니다.
- 폼 그림이 없을 때 작은 미리보기의 대체 표시가 다음 화면 갱신에서 사라지던 문제를 수정했습니다.

## 업데이트 전 꼭 읽어 주세요

1. **전체 세이브를 먼저 백업하세요.** 저장 v7은 이전 v1~v6을 읽지만 새 저장의 구버전 복원은 지원하지 않습니다. 대전·세이브 전송은 양쪽을 3.0.0으로 맞추세요.
2. **ESP의 300칸 보관 기록에는 microSD가 필요합니다.** 기존 내부 저장과 원래 SD를 함께 유지하세요. SD가 없거나 손상되면 보관 변경이 거부됩니다. 자동 포맷하지 않습니다.
3. ESP 웹 업데이트에서는 **Erase device를 선택하지 마세요.** 빈 기기용 통합 이미지를 기존 세이브 유지용 업데이트에 사용하지 마세요.
4. Android/워치는 기존 앱 위에 APK를 설치하세요. 서명 오류가 나더라도 세이브 백업 없이 앱을 삭제하지 마세요. APK는 기존 프로젝트 키로 서명된 디버그 APK입니다.
5. 전체 세이브 적용 중 전원·SD를 분리하지 마세요. 저장 실패 복구 검사는 임의 시점 전원 차단의 완전한 안전을 보장하지 않습니다.

## 다운로드

- Android Full APK: arm64-v8a / x86_64, 지방·폼 그림 포함.
- Galaxy Watch4~9 대상 Wear OS 통합 APK: armeabi-v7a / arm64-v8a, 지방·폼 그림 포함. 모든 워치 모델의 실물 동작을 확인했다는 의미는 아닙니다.
- ESP32 Web Installer ZIP: Waveshare ESP32-S3-Touch-AMOLED-1.75. [웹 설치](https://loaram.github.io/TamaPoke_ko/)에서 지방·폼 팩도 SD에 설치하세요.
- 한국어 플레이 가이드 **22쪽**과 기존 Galaxy Watch 설치 가이드 PDF를 모두 첨부합니다. `SHA256SUMS.txt`로 다운로드를 확인할 수 있습니다.

PC 도감 완성·이로치 테스트판은 비공개로만 만들며 릴리스에 넣지 않습니다. 자동 검사와 플랫폼 빌드 결과는 [검수 기록](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.0.0/README.md)에 정리합니다. 실제 ESP/폰/워치의 무선 대전·전송, SD 전원 차단과 장시간 플레이 검증은 별도로 필요합니다.
