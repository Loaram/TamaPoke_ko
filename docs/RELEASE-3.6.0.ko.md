# TamaPoke 3.6.0

도감 수집에 따라 탐색 포획 확률이 증가하는 마이너 밸런스 패치입니다.

## 도감 포획 보너스

- 전체 지방의 수집 가능한 등록 도감 100종마다 볼 배율이 0.2씩 증가합니다. 0~99종 1배, 100종 1.2배, 500종 2배, 900종부터 현재 최대 2.8배입니다.
- 종별 포획률에 볼 배율을 먼저 적용한 뒤 남은 HP 10%·상태이상 없음 조건으로 판정합니다. 최종 성공 확률을 단순히 곱하는 방식은 아닙니다.
- 포획률 3의 특별 보정 2.5%에도 배율을 적용합니다. 100종 3%, 500종 5%, 900종 7%입니다.
- 기존 도감에 즉시 적용합니다. 이로치·폼·같은 종 중복은 한 종으로 계산하며 그림 미지원 종은 제외합니다. 현재 대상은 982종입니다.
- 이번 상대는 포획 성공 후 등록되므로 100번째 종 포획에는 기존 99종 배율이 적용되고 다음 포획부터 새 단계가 적용됩니다.
- 탐색 조우·이로치·알 보너스·활력 30 소모는 유지합니다. 패배 시 포획하지 않으며 저장 실패는 포획 성공으로 처리하지 않습니다.

## 표와 설치 파일

[29쪽 플레이 가이드](https://github.com/Loaram/TamaPoke_ko/releases/download/3.6.0/TamaPoke-3.6.0-Play-Guide-KO.pdf)의 마지막 쪽에 포획률 255 캐터피, 190 피카츄, 120 단데기, 45 파이리, 3 뮤츠의 단계별 확률표를 넣었습니다. 정수 계산 때문에 배율이 올라도 같은 확률인 구간이 있으며, 99.99%와 정확한 100%는 다릅니다.

휴대전화 APK, Wear OS APK, ESP32 설치 ZIP, 기존 Galaxy Watch4-9 수동 설치 PDF, Windows 워치 설치 도우미 ZIP과 7쪽 PDF를 함께 제공합니다. 도우미는 시험판이며 이번 정식 Wear APK가 동봉되어 있습니다. [ESP 웹 설치 페이지](https://loaram.github.io/TamaPoke_ko/)에서도 업데이트할 수 있습니다.

## 업데이트와 검증

업데이트 전 세이브를 백업하고 미완료 전송·교환을 먼저 완료하세요. 앱을 삭제하지 말고 덮어 설치하세요. ESP는 원래 SD를 유지하고 Erase device를 선택하지 마세요. 저장 v7, 개체 72바이트, 배틀 5 / 거래 1은 유지합니다. Android 3036 / Wear 3037입니다.

전체 런타임 59개, SD 장애 10개, 설치 도우미 30개 검사를 통과했습니다. 모든 포획률 256개 × 도감 수 983개(251,648조합), 예시 다섯 종의 5백만 모의 포획, 도감 경계·저장 호환·실제 승리/패배 결과를 대조했습니다. [배포 전 전체 검증](https://github.com/Loaram/TamaPoke_ko/actions/runs/34109972150)을 통과한 게임 소스와 배포 소스의 동일성도 확인했습니다. 실제 기기 설치·무선·물리적 전원 차단 시험은 별도입니다. 세부 결과는 저장소의 버전별 검증 기록을 참고하세요.
