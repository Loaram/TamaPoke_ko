# 탐색 이로치와 알 선택 규칙 — 미배포 작업

다음 정식 배포 예정은 밸런스 변경에 따른 3.4.0입니다. 현재 공개 릴리스는 3.3.0이며 이 문서는 검사 브랜치의 미배포 변경 내용입니다.

## 바뀌는 규칙

- 탐색 조우 1회마다 이로치 판정은 1/100(1%). 일반/랜덤 탐색에 공통이며 연속 돌봄·도감 보너스는 붙지 않습니다. 이로치 조우와 승리 후 포획 성공은 별개입니다.
- 새 알을 만들 때 기존 보너스 공식으로 이로치 여부를 먼저 정합니다.
- 일반 알은 기존처럼 미등록 멤버가 남은 진화 계보를 우선합니다.
- 이로치 알은 일반 도감·이로치 도감의 등록 여부로 후보를 우선하거나 제외하지 않습니다. 선택 지방과 추첨 희귀도에서 부화 가능한 종을 고릅니다. 해당 희귀도에 후보가 없으면 기존처럼 아래 등급에서 찾습니다.
- 파이리·리자드·리자몽을 모두 등록했어도, 관동 일반 등급의 이로치 알에서는 파이리를 다시 뽑을 수 있습니다. 파이리를 지정하거나 확정하는 기능은 아닙니다.

## 유지되는 규칙

첫 게임의 스타팅 선택, 알의 이로치/전설 보너스 수치, 전설 도감 25종 조건, 도망 후 일반 등급 제한, 그림이 없는 부화 계보 제외, 탐색 활력 30과 조우/포획 확률을 유지합니다. 진화 분기 선택 규칙은 이번 부화 후보 변경의 대상이 아닙니다.

이미 생성된 알은 종·이로치 결과를 다시 뽑지 않습니다. 지방 변경 시 기존 희귀도와 이로치 여부를 유지하며, 지방별로 처음 뽑은 종을 기억하는 기존 동작도 유지합니다. 저장 v7과 무선 프로토콜, 포켓몬/기술/폼 번호를 변경하지 않습니다.
