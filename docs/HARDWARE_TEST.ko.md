## 설치 및 저장 유지

- [ ] 기존 데이터가 있다면 설치 전 포켓몬·레벨·별명·파티·도감 상태 기록.
- [ ] 업데이트 시 Erase device 미선택으로 설치 완료.
- [ ] 재시작 후 포켓몬·파티·도감·설정이 예상대로 유지됨.
- [ ] 새 기기 또는 별도 테스트 세이브에서 한국어 기본 선택 확인. 기존 세이브를 지워가며 이 항목을 시험할 필요는 없음.
- [ ] 기존 세이브에서 설정의 언어 버튼으로 한국어를 선택할 수 있음.
- [ ] 전원을 껐다 켜도 선택한 언어와 저장 데이터 유지.

## 화면과 조작

- [ ] 글자 네모·깨짐·잘림 없이 메뉴와 설정을 읽을 수 있음.
- [ ] 긴 포켓몬 이름과 기술명이 원형 화면 밖으로 잘리지 않음.
- [ ] 탭·좌우 넘기기·돌아가기 버튼의 표시와 터치 위치가 일치.
- [ ] 파티·박스에서 기존 영문 별명이 유지됨.
- [ ] 배틀의 이름·기술·타입·상태 메시지 표시 정상.
- [ ] 시계 설정과 재시작 후 시간 유지 확인.

## 스프라이트와 기기 기능

- [ ] 지방 팩 하나를 설치하고 포켓몬 그림·애니메이션 확인.
- [ ] 추가 팩 설치 후 지방 선택 및 도감에서 사용할 수 있음.
- [ ] SD를 읽는 동안 화면·터치가 장시간 멈추거나 재시작하지 않음.
- [ ] 소리와 음량 조절 확인.
- [ ] 배터리 표시, 화면 끄기·깨우기, 전원 켜기·끄기 확인.

## 근거리 대전

- [ ] Android 두 대를 같은 Wi-Fi에 연결하고 양쪽에서 근거리 대전 팀을 선택하면 준비 화면으로 넘어감.
- [ ] Android 17에서 처음 근거리 대전을 열 때 로컬 네트워크 권한을 허용하면 대기 화면에서 자동으로 연결이 계속됨.
- [ ] Android끼리 팀 이름·포켓몬 수가 맞고, 기술 사용·교체·승패·재대전·나가기가 양쪽에서 일치함.
- [ ] 실기에서 근거리 대전 팀을 선택하면 화면 아래에 `TamaPoke-XXXX` Wi-Fi 이름과 `tamapoke` 암호가 표시됨.
- [ ] Android를 표시된 Wi-Fi에 연결하고 “인터넷 없음” 연결을 유지한 뒤 앱에서 팀을 선택하면 실기와 준비 화면으로 넘어감.
- [ ] Android↔실기에서 팀 이름·포켓몬 수가 맞고, 기술 사용·교체·승패·재대전·나가기가 양쪽에서 일치함.
- [ ] 실기 두 대의 기존 ESP-NOW 대전도 방 만들기·참가·선택·대전·종료가 정상임.
- [ ] 90초 안에 상대가 없으면 대기 화면을 빠져나오며, 재시도하면 이전 상대가 아닌 새 상대와 연결할 수 있음.

공유기에서 기기 간 통신 차단 또는 게스트 Wi-Fi 격리가 켜져 있으면 Android끼리 서로 찾지 못할 수 있습니다. 이 경우 일반 Wi-Fi나 휴대전화 핫스팟으로 다시 확인합니다.

## Galaxy Watch4~9

- [ ] 시험할 Galaxy Watch의 정확한 모델명·크기·Wear OS·One UI Watch 버전과 `adb shell getprop ro.product.cpu.abilist` 결과를 기록함.
- [ ] Watch4~9 통합 Wear OS APK가 설치되고 앱 목록에서 실행됨.
- [ ] 원형 화면에서 제목·상태·하단 버튼이 잘리지 않고 터치 위치가 표시와 일치함.
- [ ] 앱을 닫았다 다시 열어도 포켓몬·파티·도감·설정이 유지됨.
- [ ] 워치 Wi-Fi와 휴대전화를 같은 공유기에 연결하면 워치↔휴대전화 LAN 대전이 연결됨.
- [ ] 워치를 실기의 `TamaPoke-XXXX` Wi-Fi에 연결하면 워치↔실기 LAN 대전이 연결됨.

## Android·Wear OS 기기 시각 ko.1.1.3

- [ ] ko.1.1.2에서 ko.1.1.3으로 덮어설치한 첫 실행에 기존 포켓몬과 레벨이 그대로 유지됨.
- [ ] 앱의 설정 화면을 2분 이상 열어 두면 표시 분이 기기의 날짜 및 시간 설정과 함께 바뀜.
- [ ] 앱을 백그라운드로 보낸 뒤 20분 이상 지나 돌아오면 실제 경과 시간만큼 성장함.
- [ ] 기기 시간을 뒤로 조정하고 앱으로 돌아와도 레벨이 갑자기 여러 단계 오르지 않음.
- [ ] 기기 시간을 원래 자동 설정으로 되돌린 뒤 20분마다 1레벨씩 정상 성장함.

## 세이브 전송 ko.1.1.2

- [ ] Android 원본에서 보내기, Wear OS 대상에서 받기를 선택하면 같은 6자리 확인 코드가 표시됨.
- [ ] Wear OS 원본에서 보내기, ESP32 대상에서 받기를 선택하면 전송률이 끝까지 올라감.
- [ ] ESP32 원본에서 보내기, Android 대상에서 받기를 선택하면 전체 세이브가 도착함.
- [ ] 받기 완료 뒤 적용 전까지 대상의 기존 세이브가 그대로임.
- [ ] 세이브 적용을 취소하면 대상의 기존 세이브가 그대로임.
- [ ] 세이브 적용을 확인하면 앱/기기가 재시작되고 포켓몬·파티·박스·도감·배지·설정이 원본과 같음.
- [ ] 전송 중 한쪽 Wi-Fi를 끊으면 손상 세이브가 적용되지 않고 기존 세이브가 유지됨.
- [ ] 양쪽 모두 보내기 또는 양쪽 모두 받기를 고르면 연결이 거부됨.
- [ ] 대전 중 화면 꺼짐·손목 내림·Wi-Fi 전환 후의 동작을 확인하고 연결 종료 여부를 기록함.

## 문제가 있을 때 남길 내용

화면 이름, 누른 순서, 기대했던 결과, 실제 결과, 재현 횟수, 사진/짧은 영상, 표시된 버전, 설치한 지방을 적어 주세요. 설치 실패는 어느 단계의 몇 %에서 멈췄는지도 도움이 됩니다. 전체 칩 초기화나 중요한 세이브로 강제 전원 차단 테스트를 할 필요는 없습니다.

로그인 정보와 실제 세이브의 원본 백업은 이 체크리스트에 필요하지 않습니다.
