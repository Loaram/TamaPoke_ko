> **개발 당시 기록입니다.** 정식 3.0.0은 박스 300칸·저장 v7이며 현재 사용법과 주의사항은 [릴리스 안내](RELEASE-3.0.0.ko.md) 및 [플레이 가이드](../web/guides/TamaPoke-3.0.0-Play-Guide-KO.pdf)를 기준으로 확인하세요. 아래 버전·크기·미공개 표시는 beta.3 시점의 기록입니다.

> **최신 beta.5에서는 박스가 300칸으로 확장되었습니다.** 교체 방식은 같으며 저장 구조와 ESP SD 주의사항은 [최신 안내](FORM-MOVES-BOX.ko.md)를 확인하세요. 아래 저장 크기는 beta.3 기록입니다.

폼체인지와 가라르·팔데아 체육관 베타에 추가한 미공개 기능입니다. 정식 릴리스·공개 설치 페이지는 아직 2.0.2입니다.

## 사용법

파티 또는 박스에서 포켓몬을 누르고 **데려오기**를 선택합니다. 현재 포켓몬이 홈으로 올라오려는 포켓몬의 보관 칸으로 들어가고, 선택한 포켓몬이 홈으로 나옵니다. 파티 5칸과 박스 60칸이 모두 차 있어도 별도 빈칸 없이 맞교환됩니다. 같은 칸에서 다시 데려오면 원래 포켓몬으로 돌아갈 수 있습니다.

박스 상세창에는 **데려오기 / 파티로 / 놓아주기**가 있습니다. `파티로`는 빈 파티 칸으로 이동하며, 파티가 가득 차 있으면 파티 화면에서 맞교환할 상대를 선택합니다. 반대 방향은 파티 개체 상세창에서 돌아온 뒤 같은 개체를 다시 누르고 박스에서 교체할 칸을 고릅니다. `놓아주기`는 확인 후 영구 삭제이므로 단순 교체에 사용하지 마세요.

알이 기다릴 때도 이전처럼 데려올 수 있습니다. 이때 기다리던 알을 대신하며 선택한 보관 칸은 비워집니다. 최초 스타터 선택, 기술 습득 선택, 진화 연출, 작별 처리 중에는 먼저 해당 동작을 마쳐야 합니다.

## 보존되는 것과 성장 규칙

- 키우던 포켓몬은 성장 시간(분 단위, 레벨 사이의 남은 성장분 포함), IV·훈련, 기술 네 개, 별명, 이로치, 선택한 폼, 메달을 그대로 보관합니다.
- 포만·기쁨·에너지·청결·배설물·체중·돌봄 실수·유대·수면 상태와 추가 돌봄 카운터도 개체별로 보존합니다. 교체만으로 에너지가 다시 채워지지 않습니다.
- **보관 중에는 성장·돌봄 변화가 없습니다.** 다시 데려온 때부터 이어서 키웁니다. 예를 들어 성장 1,399분에 보관한 개체는 며칠 뒤 다시 데려와도 1,399분에서 이어집니다. 1분 미만의 진행 간격은 교체 시 새로 시작합니다.
- 예전에 작별하거나 포획해서 보관한 동료는 기존의 성장 정지 규칙을 유지합니다. 이 작업은 모든 동료의 성장·진화를 다시 허용하는 밸런스 변경은 아닙니다.
- 좋은 작별은 기존 일반 최종진화 + 성장 1,440분 조건 그대로입니다. 보관 중 지난 실제 시간이나 폼 변경을 이 조건에 더하지 않습니다.
- 트레이너 이름, 도감, 체육관 배지, 전체 메달/미니게임 기록 등 플레이어 공통 기록은 개체를 교체해도 유지합니다.

## 세이브와 업데이트

기존 정식판의 26/30/34바이트 보관 기록과 beta.1/2의 TFR1 폼 기록을 읽습니다. 새 TFR2는 개체별 돌봄 상태와 교체 복구 정보를 함께 기록합니다. 파티·박스의 이전 34바이트 형식 복구 사본도 남깁니다. 이 사본만으로 폼이나 성장 재개 상태까지 복원할 수 있는 것은 아닙니다.

교체할 때 먼저 보관 개체와 홈으로 나올 개체를 하나의 체크섬 있는 기록으로 저장·확인한 뒤 홈 저장값을 갱신합니다. 중간 종료 시 다음 시작에서 해당 교체를 재개합니다. 기존 전체 세이브 가져오기 기능 자체의 전원 차단까지 원자적으로 보장하는 것은 아니므로 업데이트 전 백업을 보관하세요.

세이브 전송은 **v4, 최대 9,216바이트**입니다. 이전 v1~v3 세이브를 새 버전에서 받을 수 있지만, 새 저장을 구버전으로 보내는 것은 지원하지 않습니다. 워치·Android·ESP 사이에서 새 저장을 주고받으려면 **받는 기기부터 같은 새 버전으로 업데이트**하세요. 무선 대전 프로토콜은 폼 베타와 같은 5입니다.

## 개발 빌드

새 산출물과 검증 로그는 `build/active-swap/`에 분리합니다. PC 테스트판은 별도 `tamapoke-forms-beta.nvs`를 쓰며, 명시적으로 실제 세이브를 지정하지 않으면 정식 에뮬레이터 세이브에 접근하지 않습니다. Android/Wear OS의 앱 ID와 서명은 기존 계열을 유지합니다. 실제 워치/휴대폰/ESP 설치·저장 공간·터치·전원 차단·기기간 무선 전송 검증은 별도로 필요합니다.

38개 회귀 테스트에 `active_swap`을 추가했습니다. 실제 파티/박스 버튼, 꽉 찬 박스 마지막 칸, 정확한 개체 상태 왕복, 기존 세이브, 저장 실패, 재시작 복구, 전체 저장 이전을 확인합니다. 공개 버전을 만들 때는 이 내용을 플레이 PDF에도 반영해야 합니다.
