# TamaPoke 한국어판 3.1.1

앱을 다시 실행했을 때 소리 설정과 수면 상태가 초기화되던 저장 복원 오류를 수정한 정식 패치입니다. 작은 오류 수정이므로 버전 규칙에 따라 3.1.1로 올렸습니다.

## 수정 내용

- Android·Wear OS에서 소리 켜기/끄기와 선택한 음량을 다시 실행해도 유지합니다.
- 직접 재운 포켓몬은 앱 종료 후에도 잠든 상태를 유지합니다. 수면 중 경과 시간은 기존대로 분당 활력 +8을 적용하며, 사용자가 다시 수면 버튼을 누르면 깨웁니다.
- 300칸 박스 기록을 읽다가 중단하여 뒤쪽 설정을 버리던 4KB 제한을 수정했습니다. PC 에뮬레이터의 같은 문제도 수정했습니다.
- 파일 전체가 정상일 때만 복원합니다. 읽기 실패 시 원본을 보존하며, 저장 실패를 완료로 처리하지 않고 다음 저장 때 재시도합니다.

## 업데이트와 저장

앱을 삭제하거나 데이터를 지우지 말고 기존 앱 위에 APK를 업데이트하세요. 업데이트 전에 세이브를 백업하는 것을 권장합니다. 기존 프로젝트 서명키를 유지했으며 Android versionCode는 3020, Wear는 3021입니다.

이전 버전에서 이미 초기화되어 덮어쓴 정보까지 자동으로 되살릴 수는 없습니다. 업데이트 후 원하는 소리·음량을 한 번 설정하고, 수면 버튼으로 재운 뒤 종료·재실행을 확인하세요. 저장 오류 안내가 뜨면 앱 데이터를 지우지 말고 원본 보존 상태에서 문의해 주세요.

저장 v7·무선 프로토콜 5·기존 포켓몬 번호와 폼·기술 데이터는 유지합니다. 성장·훈련·탐색·작별 등의 밸런스 변경은 없습니다. ESP32도 같은 3.1.1 버전으로 제공하며 기존 NVS 파티션과 SD 보관 방식을 바꾸지 않습니다. ESP32는 계속 microSD가 필요합니다.

## 다운로드

- Android Full APK: 휴대전화 ARM64 및 Android 에뮬레이터 x86_64.
- Wear OS Galaxy Watch4~9 APK: ARM32/ARM64 통합판.
- ESP32 Web Installer ZIP.
- 3.1.1 한국어 플레이 가이드 PDF: 총 24쪽, 소리·수면 유지 안내 포함.
- Galaxy Watch4~9 설치 가이드 PDF: 기존 내용 그대로 동봉.
- SHA256SUMS.txt: 위 다섯 파일의 검증 해시.

## 검증 범위

48개 런타임 검사, SD 저장 실패 모의 검사 10개, 한국어·폼·설치 페이지 검사 및 Android·Wear·ESP32·PC 빌드를 확인합니다. 실제 파일을 닫고 다시 여는 검사에서 22,116바이트 박스와 뒤쪽 설정, 300번째 포켓몬, 수면·활력·수동 깨우기, 잘린 파일 보호 및 저장 재시도를 확인합니다. 실제 휴대전화·워치·ESP 설치, 물리적 전원 차단과 기기 간 무선 시험은 하지 않았습니다. 상세 결과는 [검증 기록](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.1.1/README.md)에 남깁니다.
