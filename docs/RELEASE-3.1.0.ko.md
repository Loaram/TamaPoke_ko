# TamaPoke 3.1.0 — 박스 정렬·동료 성장·개체값

박스에 **가나다순 · 번호순 · 레벨순 정렬**을 추가했습니다. 사용자가 이번 묶음을 편의 기능 개선으로 분류하여 마이너 버전인 3.1.0으로 확정했습니다.

## 사용 방법

1. 파티에서 박스를 열고 아래 **정렬**을 누릅니다.
2. 가나다순(공식 한국어 종 이름, 별명·폼 이름 제외), 번호순(전국도감 번호 오름차순), 레벨순(높은 레벨부터)을 선택합니다.
3. 확인창에서 **예**를 누르면 **300칸 전체**를 정렬하고 첫 페이지로 돌아옵니다. 아니요는 정렬 메뉴로 돌아갑니다.

빈칸은 뒤로 모읍니다. 가나다·번호가 같으면 레벨 높은 순, 레벨이 같으면 번호순이며 모든 기준이 같으면 기존 순서를 유지합니다. 정렬은 선택할 때 한 번 적용하며 새로 포획·보관한 개체를 자동 정렬하지 않습니다. 기존 배치로 되돌리기 버튼은 없습니다.

취소하면 원래 페이지와 교체 선택을 유지합니다. 적용하면 칸 위치가 바뀌므로 기존 교체 선택은 취소합니다. 저장 실패는 오류로 표시하고 메모리의 원래 순서를 복구합니다. ESP는 정렬 임시 공간을 PSRAM에 두며 기존 SD 이중 저장을 사용합니다.

## 동료 성장과 개체값 표시

포획·좋은 작별 동료도 **홈으로 데려오면 현재 레벨에서 20분마다 1레벨**씩 성장합니다(최대 100레벨). 조건을 갖추면 일반 진화와 레벨업 기술 습득도 가능합니다. 보관 중에는 시간이 멈추고 다시 데려오면 이어집니다. 기존 세이브에도 적용됩니다.

기존 보호는 유지합니다. **도망가지 않고 좋은/일반 작별을 다시 하지 않습니다.** 파티·박스에서 놓아주기는 가능합니다.

파티·박스 상세창은 **공격 99(31)**처럼 표시합니다. **괄호 밖은 현재 능력치, 괄호 안은 개체값(0~31)**입니다. 공격·방어·속도·체력 모두 표시하며 값을 다시 뽑거나 변경하지 않습니다.

## 유지되는 내용

현재 키우는 개체와 파티는 정렬 대상이 아닙니다. 별명·이로치·폼·기술·개체값·훈련·돌봄 기록을 그대로 유지합니다. 작별 횟수, 20분 성장 간격과 포획 확률은 변경하지 않았습니다. 박스 직접 놓아주기, 교체, 50페이지 이동 기능은 유지합니다.

저장 v7 / 무선 프로토콜 5는 그대로이며 기존 세이브를 사용합니다. 업데이트 전 전체 세이브를 백업하세요. ESP는 원래 microSD를 유지하고 초기화/Erase를 선택하지 마세요. 앱은 기존 앱을 삭제하지 말고 덮어 설치하세요. 새 저장을 구버전으로 되돌리는 것은 지원하지 않습니다.

## 배포 파일과 설명서

- Android APK: ARM64 + x86_64, versionCode 3018.
- Wear OS APK: ARM64 + ARMv7, Galaxy Watch4–9용, versionCode 3019.
- ESP32-S3 설치 ZIP 및 [브라우저 설치 페이지](https://loaram.github.io/TamaPoke_ko/).
- **24쪽 플레이 가이드**: 23쪽 정렬, 24쪽 동료 성장·진화·보호 규칙과 개체값 설명.
- **Galaxy Watch 설치 가이드**: 기존 문서 그대로 동봉.
- SHA256SUMS.txt: 배포 파일 검증용.
