# 3.8.0 - 하루 두 번 알 받기

좋은 작별을 메뉴의 **알 받기**로 교체하는 육성 방식·밸런스 수정이므로 마이너 버전을 올렸습니다.

- 이름을 눌러 메뉴 → 알 받기 → 확인. 현재 포켓몬을 파티 우선·빈칸이 없으면 박스로 보관하고 홈에 새 알을 놓습니다.
- 레벨 73·성장 24시간·일반 최종진화 조건은 없습니다. 포획했거나 다시 데려온 동료도 가능합니다.
- 메뉴 수령은 하루 2회. 기기 현지 날짜의 자정에 초기화하며 미사용분은 이월하지 않습니다. 재시작·교체·보관 개체 놓아주기로 횟수가 늘어나지 않습니다.
- 이미 알이 있거나 파티와 박스 모두 가득 차면 수령하지 않고 횟수도 차감하지 않습니다. 기술 선택·진화·통신 등 진행 중인 작업부터 마치세요.
- 현재 포켓몬의 폼·이로치·IV·훈련·기술·유대·성장 시간을 보존합니다. 공용 활력도 그대로입니다.
- 연속 돌봄·도감에 따른 이로치/전설 알 보너스는 유지합니다.
- **방치 후 도망과 자동 알은 사용자 선택에 따라 기존대로 유지**하며 메뉴 2회와 별개입니다. 첫 시작 알도 별개입니다.
- 현재 포켓몬을 오래 눌러 보내던 기능은 제거합니다. 개체 정리는 파티·박스의 놓아주기를 이용하세요.
- 저장 중단 시 같은 알 수령을 재개하는 복구 기록을 추가했습니다. 저장 확인 안내가 뜨면 초기화하지 말고 저장 공간·SD 연결을 확인한 뒤 다시 확인을 누르세요.

이전 포켓몬·도감·세이브를 유지합니다. 저장 v7에 일일 횟수와 복구 키를 추가하며 개체 72바이트·폼/기술 번호는 그대로입니다. 새 데이터를 구버전으로 되돌리면 새 횟수 필드가 사라질 수 있으므로 양쪽을 3.8.0으로 맞춰 전송하세요. Android 3048 / Wear 3049, 폰·워치·ESP에 동일 적용합니다.

폰/워치 APK, ESP ZIP, Windows 워치 설치 도우미, 최신 플레이·설치 PDF와 기존 수동 설치 PDF를 함께 배포합니다. 공개 전 최종 커밋의 65개 런타임·통신·SD·ESP 검사 성공이 필수입니다. 실제 기기 설치와 물리적 전원 차단 검증은 별도입니다.
