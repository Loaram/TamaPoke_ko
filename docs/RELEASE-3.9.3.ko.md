# TamaPoke 3.9.3 — ESP 배틀 후 저장 오류 수정

기능·밸런스 변경 없는 버그 패치입니다. 보고된 원형 ESP에서 수정 시험판의 해결 확인을 받고 정식 배포합니다.

## 수정

- 배틀 준비 때 현재 포켓몬을 통째로 복사하여 ESP 저장 연결까지 함께 닫히던 문제를 수정했습니다. 탐색·포획 후 원래 포켓몬을 데려올 때 `교체 저장 확인 필요`에서 멈추고 `다시 확인`으로 풀리지 않던 경로입니다.
- 이제 배틀에 필요한 포켓몬 데이터만 복사합니다. 같은 실수가 다시 들어가지 않도록 저장 연결을 가진 포켓몬 객체의 복사를 컴파일 단계에서 막습니다.
- 음악이 끝난 뒤 남은 음 때문에 오디오 작업이 쉬지 못해 재부팅될 수 있던 별도 문제도 수정했습니다.
- 실제 저장 실패 시 기록을 보호하는 검증·복구 기능은 유지합니다. 오류를 숨기거나 저장 확인을 건너뛰지 않습니다.

## 확인한 내용

기존 코드에서 탐색 후 저장 실패, 포획 개체 보관 유지, 재시도 실패, 재시작 후 교체 복구를 재현했습니다. 수정 후 히드런/무한다이맥스 무한다이노와 코라이돈/루나아라 조합을 검사했고, 보고 기기에서 사용자도 해결을 확인했습니다.

ESP의 저장 연결 수명을 모사하는 회귀 검사와 실제 오디오 작업 코드를 실행하는 검사를 추가했습니다. 모든 ESP·Android·워치 모델에서 실기 검증했다는 뜻은 아닙니다.

## 업데이트

저장 v7, 개체 기록 72바이트, 통신 규격, 게임 규칙과 SD 그림 팩은 그대로입니다. 업데이트 전 백업하고 기존 앱·SD를 유지하세요. 앱 삭제·세이브 초기화·SD 포맷은 필요하지 않습니다. ESP 설치 중 `Erase device`를 선택하지 마세요.

Android Full, Wear OS Watch4–9, 기존 원형 ESP 펌웨어를 제공합니다. Android versionCode 3058 / Wear 3059. 플레이 가이드, 기존 워치 수동 설치 가이드, Windows 워치 설치 도우미와 설명서도 함께 첨부합니다. ES3C28P 실험 포트는 포함하지 않습니다.
