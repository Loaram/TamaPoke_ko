# 3.0.0-beta.5 — 폼별 기술 선택과 300칸 박스

> **개발 당시 기록입니다.** 정식 3.0.0에도 이 기능이 포함되며 저장 전송은 v7, 박스에는 이전/다음 및 빠른 페이지 선택 버튼이 추가됐습니다. 현재 규칙과 업그레이드 주의사항은 [릴리스 안내](RELEASE-3.0.0.ko.md)를 보세요. 아래 미공개 표시는 beta.5 당시 상태입니다.

아직 공개하지 않은 3.0.0 베타의 추가 작업입니다. 정식 배포 버전은 2.0.2 그대로이며, 공개 업로드나 실제 기기 설치는 하지 않았습니다.

## 플레이 방법

- 폼 선택 후 새로 배울 수 있는 기술이 있으면 **기술 선택** 화면이 열립니다. 위쪽은 새 기술, 아래 네 줄은 현재 알고 있는 기술입니다. 교체할 줄을 직접 누르세요. 빈칸이 있어도 이번 폼 기술 선택은 사용자가 고릅니다.
- **배우지 않기**는 기존 네 기술을 그대로 유지합니다. 여러 기술이 추가되면 순서대로 선택합니다. 위아래 뒤로 가기로 제안을 닫아도 이미 확정한 기술은 저장됩니다.
- 현재 포켓몬의 기술창, 파티·박스 상세창의 기술 줄을 눌러 나중에 다시 배울 수 있습니다. 레벨이 멈춘 동료도 현재 레벨에서 가능한 기술을 고를 수 있습니다.
- 폼 변경은 네 기술을 통째로 초기화하지 않습니다. 다만 로토무 가전 기술, 우라오스의 유파별 전용기, 큐레무 합체기, 거수참·거수탄·이차원러시는 해당 폼에서만 전투에 사용할 수 있습니다. 다른 폼에서는 저장된 기술을 지우지 않고 그 전투 칸을 발버둥으로 대신합니다. 원래 폼으로 돌아가면 다시 쓸 수 있습니다.
- 박스는 **300마리 / 6마리씩 50페이지**입니다. 아래 `1/50`처럼 페이지 숫자가 표시되며 좌우로 넘깁니다. 전투 인원은 현재 포켓몬 1마리와 파티 5마리로 그대로입니다.
- 일반 60·메가 70·강력한 폼 80레벨 해금, 좋은 작별의 일반 최종진화·성장 24시간 조건은 바꾸지 않았습니다.

## 기술 데이터 범위

PokeAPI 고정 커밋 `d4f9a4af58ade123fbc0558f68b1c69daa97d9e4`, 남청의 원반까지의 비교 가능한 작품 데이터를 사용했습니다. PokeAPI는 커뮤니티 데이터셋이며 공식 게임 데이터 배포물이 아닙니다.

- 습득 기술/레벨이 다른 62개 폼과 로토무 5개·검왕/방패왕 2개, 총 **69개 폼의 별도 기술 목록**을 추가했습니다.
- 차이가 없는 폼과 현재 데이터 범위 밖의 신규 메가진화 12개는 기본형 목록을 상속합니다. 자료가 없다는 이유로 빈 목록을 만들지 않습니다.
- 기본형의 기존 기술 695종 번호를 유지하고 22종을 끝에 추가했습니다. 총 **717종**, 빈 기술을 포함한 테이블은 718항목입니다.
- 폼별 최초/진화 기술과 레벨업 기술, 기존 축약 기술머신 범위 내 해당 폼의 호환성을 반영합니다. 모든 시대의 모든 기술머신·교배·가르침 기술을 무제한 합치는 시스템은 아닙니다.
- 수류연타의 3회 급소 공격, 셸암즈의 물리/특수 선택, 프리즈볼트·콜드플레어의 준비 턴을 반영합니다. 급소 배율 등은 기존 TamaPoke 전투 규칙입니다.
- 원작 특수 효과를 모두 재현하지는 않습니다. 비검천중파의 압정 설치, PP가 없는 게임에서의 섬뜩한주문 PP 감소 등은 현재 엔진에 없는 효과로, 기술의 기본 공격/지원 기능과 기존 엔진이 지원하는 효과만 사용합니다. 이것을 원작 전투 규칙 완전 구현으로 표시하지 않습니다.

## 저장과 업데이트 주의사항

**업데이트 전 세이브를 내보내 보관하세요. 이전 버전으로 되돌리는 것은 지원하지 않습니다.**

- 18/60칸 구형 저장 및 TFR1/TFR2 베타 기록을 읽습니다. 기존 위치·별명·폼·기술·돌봄 기록은 보존하고 새 240칸만 비웁니다.
- 새 보관 형식은 `TFR3`, 16비트 슬롯 수, 72바이트 레코드 306칸 + 활성 교체 복구 기록 1칸, 총 22,116바이트입니다. 파티의 숨겨진 구버전 여섯 번째 기록도 유지합니다.
- 세이브 전송은 **v5 / 최대 32,768바이트**이며 이전 v1~v4를 받습니다. 새 세이브를 구버전에 보내는 것은 거부합니다. 워치·안드로이드·ESP 모두 이 변경을 적용한 빌드끼리 전송하세요.
- **ESP에는 SD 카드가 필요합니다.** 기존 내부 NVS 저장 영역은 약 20KB이므로 영역을 강제로 늘리거나 기존 플래시를 지우지 않습니다. SD 루트의 `tamapoke-roster-<기기번호>-0.bin`, `-1.bin` 두 파일에 보관 스냅샷을 번갈아 쓰고, 검증 후 내부 저장의 선택 표식을 전환합니다.
- ESP의 SD 파일을 임의로 지우거나 다른 카드로 바꾸지 마세요. 다른 ESP로 옮길 때도 파일만 복사하지 말고 게임의 세이브 전송을 이용하세요. 두 파일만으로는 도감·배지·현재 포켓몬까지 포함한 전체 백업이 아닙니다.
- SD 쓰기 실패·분리·파일 손상을 감지하면 보관 기록을 읽기 전용으로 보호합니다. 업데이트 이전 NVS 기록과 60칸 복구용 사본은 보존하지만, 이를 최신 300칸 기록인 것처럼 자동 복원하지 않습니다. 카드를 다시 연결한 뒤 재시작하고 필요하면 내보낸 전체 세이브로 복원하세요.
- SD 마운트 실패 시 자동 포맷하지 않습니다. Android·Wear OS·PC는 기존 앱/에뮬레이터 내부 저장 파일을 계속 사용합니다.

## 재생성 및 검사

`tools/audit_form_moves.py` → `tools/fetch_form_moves.py`는 고정 데이터의 조사/원본 생성 단계입니다. 일반 오프라인 빌드는 이미 포함된 `data/forms/moves.json`에서 `tools/gen_moves.py`, `tools/gen_form_moves.py`, 한국어 이름/글꼴 생성기를 사용합니다.

검사에는 300칸 저장·전송·복원, 256/300번째 슬롯 선택, 파티/박스/현재 포켓몬 교체, TFR1/TFR2 이전, 사용자 기술 교체와 거절, 폼 전용기 분리, SD 분리·짧은 쓰기·선택 표식 저장 실패·파일 손상·초기화 모의 검사를 포함합니다. 모의 검사/컴파일 성공은 실제 기기 SD·터치·무선 검증을 대신하지 않습니다.
