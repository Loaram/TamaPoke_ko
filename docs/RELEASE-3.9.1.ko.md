# TamaPoke 3.9.1

ESP 연속 돌봄 기록의 날짜 불일치 버그를 수정한 패치입니다. 기능·확률·활력 밸런스는 바꾸지 않습니다.

- 폰·워치·ESP 간 전체 세이브를 적용할 때 받는 기기의 날짜 기준에 맞춰 돌봄 달력을 보정합니다. 연속일수·알 수령 사용 횟수·개체별 당일 유대 한도·보관 기록을 유지합니다.
- 날짜 차이만으로 연속 보너스가 사라지거나 연속일수가 1일로 바뀌거나 레벨이 급상승하는 것을 방지합니다. 시리얼 IMPORT에도 같은 보정을 적용합니다.
- ESP 시계의 신뢰성을 확인하고 초기화·역행 시 마지막 저장 시각부터 이어갑니다. 자정 직후 입력 전에 날짜를 갱신합니다.
- 오래된 저장에서 미래 돌봄 날짜 때문에 멈춘 기록을 한 번 보정합니다. 이미 초기화되어 사라진 과거 연속일수를 최고 기록으로 덮어쓰지는 않습니다.
- 파티·박스 교체의 임시 개체가 당일 유대 사용량을 새로 충전하지 않도록 수정했습니다.

## 업데이트

Android 3054 / Wear OS 3055. 앱을 삭제하지 말고 업데이트하세요. ESP는 전체 삭제 없이 설치하고 기존 microSD를 유지하세요. 설치 전 세이브 백업을 권장합니다.

저장 v7·72바이트 포켓몬 기록·통신 프로토콜 5를 유지하며 기존 세이브를 읽습니다. 새 선택 필드 dayOff로 기기별 날짜 차이를 표현합니다. 날짜 보정 기능을 안전하게 사용하려면 양쪽을 3.9.1로 맞추세요. 구버전으로 되돌리는 것은 지원하지 않습니다.

정식 Android·Wear OS APK, ESP32 설치 ZIP, 31쪽 플레이 가이드, Galaxy Watch 수동 설치 PDF, Windows 워치 설치 도우미와 설명서를 함께 제공합니다.

## 검사 범위

과거/미래/동일 날짜로 전송, 반복 왕복, 다음 날·빠뜨린 날, 알 소진 유지, 개체별 유대 한도, 300번째 박스 개체 교체, 저장 실패 롤백, 기존 기록 복구를 실제 게임 코드로 검사합니다. 전체 회귀 검사와 ESP 빌드를 통과한 파일만 공개합니다. 이번 패치의 실제 기기 간 전송·장기 RTC 유지 검사는 별도입니다.
