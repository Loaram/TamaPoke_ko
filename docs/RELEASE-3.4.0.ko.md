# TamaPoke 한국어판 3.4.0

파티 생존 판정 오류를 수정하고 탐색 이로치·알 후보 규칙을 조정한 정식 업데이트입니다. 기능 수정과 밸런스 변경이므로 마이너 버전 3.4.0으로 배포합니다.

## 배틀에서 남은 동료를 끝까지 사용

- 마지막 순서의 포켓몬이 쓰러져도 앞쪽에 살아 있는 동료가 있으면 배틀을 계속합니다.
- 다음 순서부터 파티 전체를 한 바퀴 확인하며, 이미 쓰러진 동료는 건너뜁니다. 교체했던 동료의 남은 HP를 유지합니다.
- 탐색·체육관·근거리 대전에 공통 적용하며, 근거리 상대의 생존 판정도 같습니다.
- 양쪽이 같은 턴에 쓰러지면 두 팀의 남은 동료를 확인합니다. 양쪽 모두 남아 있으면 차례로 교체하며 추가 공격은 발생하지 않습니다.
- 근거리 대전에서는 턴 종료의 독·화상 피해와 자동 교체 이후의 위치·HP를 상대에게 전달합니다.

## 이로치와 부화

- 정식 탐색의 이로치 조우 확률을 **1/100(1%)**로 변경합니다. 일반·랜덤 탐색 공통이며 도감·연속 돌봄 보너스는 더하지 않습니다.
- **이로치 알은 도감 미획득 우선 조건을 적용하지 않습니다.** 파이리·리자드·리자몽을 모두 모았어도 관동에서 이로치 파이리가 다시 부화할 수 있습니다.
- 일반 알의 미등록 진화 계보 우선, 첫 스타팅 선택, 지방·희귀도·그림 지원 조건은 유지합니다. 이로치 알도 원하는 종이 확정되는 것은 아닙니다.
- 이미 생성된 알의 종과 이로치 결과를 다시 추첨하지 않습니다. 알의 이로치·전설 보너스 공식은 그대로입니다.

## 기존 저장과 업데이트

저장 v7, 무선 프로토콜 5, 기존 포켓몬·폼·기술 번호와 300칸 박스를 유지합니다. 탐색 활력 30, 조우 종류 비율과 승리 후 포획 확률은 그대로이며 이로치 조우와 포획 성공은 별개의 판정입니다.

전체 세이브를 백업한 뒤 앱을 삭제하거나 데이터를 지우지 말고 덮어설치하세요. 기존 서명키를 유지하며 Android versionCode는 3026, Wear는 3027입니다. 근거리 대전은 양쪽을 3.4.0으로 맞추세요. ESP는 원래 microSD를 유지하고 저장 유지 업데이트에서 Erase device를 선택하지 마세요.

## 파일과 검증

Android Full APK(ARM64/x86_64), Galaxy Watch4~9 Wear APK(ARM32/ARM64), ESP32 Web Installer ZIP, 25쪽 한국어 플레이 가이드, 기존 내용 그대로의 워치 설치 가이드, SHA256SUMS.txt를 첨부합니다.

전체 53개 런타임 묶음, SD 실패 검사 10개와 플랫폼 빌드로 검증합니다. 파티 6칸의 활성/생존 조합 30개, 생존 동료 없는 경우, 체육관·근거리 호스트/상대, 동시 기절, 알 재부화 및 세이브 호환을 포함합니다. 실제 기기 설치·기기 간 무선·물리적 SD 전원 차단 시험은 별도입니다. [검증 기록](https://github.com/Loaram/TamaPoke_ko/blob/main/docs/qa/3.4.0/README.md).
