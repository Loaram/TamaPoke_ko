# TamaPoke 워치 설치 도우미 (Windows 시험판)

Windows 10/11 x64 PC에서 Galaxy Watch의 Wear OS 앱을 설치·업데이트하는 한국어 GUI입니다.
Python, Android Studio, 명령어 입력이 필요하지 않습니다. 워치 APK와 ADB가 동봉됩니다.
게임 버전은 동봉된 version.txt에서 확인합니다. 실제 워치 페어링·설치는 아직 검증하지 않았습니다.
현재 배포는 **정식 게임 3.5.1 + 설치 도우미 시험판**입니다. Galaxy Watch4-9용 공용 Wear APK를 동봉하며 모든 모델의 실기 검증을 뜻하지 않습니다.
자세한 7쪽 설명서는 동봉 `Watch-Installer-Guide-KO.pdf` 또는 도우미의 **그림으로 보는 PDF 설명서** 버튼으로 엽니다.

## 사용 순서

1. ZIP을 PC의 폴더에 **모두 압축 풀기** 합니다.
2. `TamaPoke-Watch-Installer.exe`를 실행합니다.
3. PC와 워치를 같은 Wi-Fi에 연결합니다. 워치 설정에서 개발자 모드, ADB 디버깅, 무선 디버깅을 켭니다.
4. 워치의 **새 기기 페어링** 화면에서 IP 주소·페어링 포트·6자리 코드를 옮겨 적고 **PC 등록 (페어링)**을 누릅니다. 이 PC를 이미 등록했다면 생략합니다.
5. 워치에서 뒤로 돌아가 **무선 디버깅 기본 화면**의 연결 포트를 입력하고 **워치 연결 확인**을 누릅니다. 두 포트는 다릅니다. IP가 달라졌다면 IP도 수정합니다.
6. 표시된 연결 기기를 확인하고 **설치 / 업데이트**를 누릅니다. 파일이 커서 Wi-Fi 상태에 따라 몇 분 걸릴 수 있습니다. 최대 10분 후 시간이 초과되면 워치 앱 목록을 먼저 확인하세요.
7. **워치에서 게임 열기**를 누릅니다. 끝나면 워치의 무선 디버깅을 끕니다.

## 업데이트와 문제 해결

- 설치는 `adb install -r`로 진행합니다. 앱 삭제·데이터 초기화·다운그레이드를 실행하지 않습니다. 설치 전 확인창에서 대상 주소와 백업 안내를 확인합니다. 자동 백업 기능은 없습니다.
- 3.5.1의 미완료 포켓몬 전송·교환은 같은 상대와 재연결해 양쪽 모두 완료한 뒤 업데이트하세요. 전체 세이브 보내기/받기로 별도 기기에 백업할 수 있지만, 대상에서 적용하면 대상의 기존 저장을 덮어씁니다. 한 마리 전송은 전체 백업이 아닙니다.
- 서명 불일치: 기존 앱을 삭제하지 말고 제작자에게 같은 서명의 APK를 요청하세요.
- 연결 실패: 워치 화면을 켜고 같은 Wi-Fi인지, 포트가 바뀌었는지 확인합니다. 공용/게스트 Wi-Fi는 기기끼리 통신을 차단할 수 있습니다. PC와 워치가 통신 가능한 다른 네트워크에서 시도하세요.
- 방화벽에 연결 허용 창이 나타나면 사용하는 신뢰할 수 있는 개인 네트워크에서 ADB 연결을 허용합니다. 프로그램은 방화벽 설정을 자동 변경하지 않습니다.
- 압축 안에서 실행하거나 파일을 따로 옮기면 실행되지 않습니다. EXE·APK·ADB·DLL·SHA256SUMS.txt를 같은 폴더에 두세요.
- SHA-256은 누락·손상을 확인합니다. 배포자의 신원을 보증하는 전자서명이 아닙니다. 이 시험판 EXE에는 코드 서명이 없습니다.
- Windows에서 차단하면 출처를 확인하고 제작자에게 문의하세요. 백신이나 Smart App Control을 끄지 마세요. 기존 수동 설치 PDF를 대안으로 참고할 수 있습니다.
- 구형 OS에서 ‘새 기기 페어링’ 메뉴가 없다면 가능한 워치 OS 업데이트를 먼저 확인하세요. 이 도우미는 코드 기반 무선 디버깅 흐름을 기준으로 합니다.
- PC와 워치의 페어링 등록은 유지됩니다. 제거하려면 워치의 무선 디버깅 → 등록된 기기에서 이 PC를 삭제합니다.

## 개발 및 검증

검수한 PDF를 먼저 준비한 뒤 `.venv/Scripts/python.exe tools/build_watch_installer.py --guide output/pdf/TamaPoke-3.5.1-Watch-Installer-Guide-KO.pdf`를 실행합니다.
Windows 기본 .NET Framework C# 컴파일러와 로컬 Android SDK의 platform-tools를 사용하며, 게임의 현재 FW_VERSION에 해당하는 Wear APK만 동봉합니다.
출력은 `build/watch-installer/`입니다. 같은 출력 폴더를 덮어쓰지 않으므로 재빌드는 `--out build/watch-installer-rebuild`처럼 새 경로를 지정합니다.
특정 기존 APK로 만들 때는 `--game-version 3.5.1`을 지정합니다. `--preview`는 숨긴 Windows 창을 렌더링하여 화면 확인용 PNG도 만듭니다.
ADB/입력/손상 파일 모의 검사와 화면 생성 검사를 실행하고 ZIP CRC·SHA-256을 확인합니다.
게임 펌웨어와 APK는 변경하지 않으며 게임 정식 릴리스를 새로 만들지 않습니다.
실제 워치에서 최초 페어링, 재연결, 신규 설치, 기존 세이브를 유지하는 업데이트, 게임 실행을 추가 확인해야 합니다. 그전까지 도우미는 시험판으로 표시합니다.
